# 星夜 · 角色配套的精致动态空间

这次改动将原有六套示范背景升级为适合近距离角色聊天的空间。继续使用原来的环境 ID、角色允许列表与角色独立存档；不新增独立于角色的公共背景菜单，不调整角色的镜头、取景或动作。

## 空间与材质

| 环境 ID | 设计与实际三维细节 | 局部动态 |
| --- | --- | --- |
| `evening` 静夜小屋 | 月色花园窗景、木窗深框、亚麻帘、细木格栅、布面书脊、曲面陶瓶、软包座椅、褶皱灯罩 | 两片顶部固定的窗帘、两组有根的植物 |
| `sunroom` 日光房 | 晨光园林窗景、低饱和石灰墙、木纹地板、书架、织物坐垫与陶盆 | 两片窗帘、两组植物 |
| `studio` 小影棚 | 深色墙面、木格栅、侧边园林景窗、布面座椅与暖灯 | 两片窄帘、两组植物 |
| `garden` 花园 | 连续实体地面、石质活动露台、错落石阶、开敞木架、真实弯曲叶片与多瓣花簇 | 十组轻微叶梢/花簇摆动 |
| `seaside` 海边 | 蓝小时海岸远景、实体木质露台、细栏杆、金属横索、接收光照的海面、植物与休息椅 | 海面法线/纹理缓慢流动、两组植物 |
| `courtyard` 清风小院 | 保留原始 CC0 GLB 的地面和建筑结构，增加木格栅、曲面陶盆、植物、软包长椅、窄帘与园林远景 | 两片窄帘、三组植物 |

木材、亚麻、石灰面和水面分别使用可重复的颜色纹理与法线纹理。常见家具用圆角网格与旋转曲面塑形，叶片使用带中央脊线和弯曲的尖叶网格，替换原来的球形树冠和椭球叶片。

远景是三张原始生成图：`Assets/EnvironmentArt/NightGarden.png`、`MorningGarden.png`、`BlueHourCoast.png`，各为 1536×1024；生成提示和来源过程保存在同目录 `generation.json`。它们只构成窗外/远方的层次，不替代前景地面、窗框、植物、家具和阴影。不同窗框/背景面的宽高比采用独立材质与居中 UV 裁切，保持图像比例而非拉伸。远景不投射阴影，也不加入 surface/accent 配色绑定，防止用户调色把画面刷成纯色。图片保留原始非二次幂尺寸，避免导入时改变3:2比例；开启 mipmap，iOS 使用 ASTC 6×6，导入上限 2048；不通过 Resources 重复加载。

## 角色绑定与隔离

角色集合仍由 `CharacterCollections.json` 声明 `environments` 和 `defaultEnvironment`。本轮保留既有选择：初音默认静夜小屋，Luma 默认影棚，真人角色默认日光房，优可默认小院等。背景选择、配色、摆设开关与方向继续跟随该角色的记录；切换角色恢复各自记录，不继承上一个角色的选择。

可复用的不可变背景资源只打包一次，角色包通过稳定环境 ID 引用各自允许使用的子集。共享网格/贴图不等于共享用户设置。角色创建时复制自己的集合与配置，原角色或其他角色的设置不会因此变化。

六个环境内容版本升级为 `1.1.0`；环境 ID、调色 ID、API 主版本保持不变。清单的 `extensions.app.starry.presentation` 只标识宿主提供的第二版美术呈现。外部 XEP 包仍是经过校验的静态 GLB，不因此获得注入执行代码或任意动画的权限。庭院的原始 GLB、许可和校验散列保留不变，宿主增强层在生成 runtime manifest 时补充实际节点绑定。

## 动态与性能边界

`EnvironmentAmbientMotion` 为一个活动背景驱动局部运动。每片帘布的顶端顶点权重为零；下摆最大位移 2.4 厘米，叠加两个缓慢频率。植物绕根部轻微转动，声明上限 1.35°，没有整体场景浮动。海面通过已有不透明 Lit 材质的纹理变换和法线强度呈现微波，不增加透明覆盖层或逐帧创建材质。

主光、补光、轮廓光仍由 `EnvironmentDirector` 管理，光源和阴影不随环境动态抖动。使用已有阴影设置，不添加粒子系统、实时额外灯光、动态反射探针或物理模拟。停用背景不执行 Update；关闭摆设后跳过相关隐藏节点。App 暂停或失焦时冻结环境局部时间，恢复后的单次时间步长限制在 0.05 秒。

运行时网格、顶点数组、权重和材质属性块只初始化一次。窗帘小位移保留已有褶皱法线，避免逐帧重建法线；没有逐帧 LINQ、集合构建或材质复制。同材质静态几何在编辑器生成阶段合并，每棵植物内部合并。庭院保留独立的墙与花盆 Renderer，避免合并后的包围盒横跨角色净空区，造成保守碰撞预检误判。

预算仍为每背景最多 256 个 Renderer、250,000 顶点，本版额外限制最多 24 个动态节点。实际生成结果由审查报告给出。这些预算和模拟器流畅度都不构成真机稳定 120 FPS 的承诺。

系统“减少动态效果”尚未传递到 Unity 环境层；本版沿用 App/Unity 的暂停和失焦抑制，不宣称已完成该系统偏好的跨层接入。

## 验证与可观测性

`RefinedEnvironmentReview.Rebuild()` 执行场景生成、现有构建校验和环境审查；`Review()` 直接打开保存场景进行审查。两者不申请 GPU 渲染，可用于 `-nographics` 流程。审查覆盖六套绑定、顶点/Renderer 预算、远景有贴图、远景不受调色覆盖、3 秒真实局部运动采样、帘顶固定、停用背景局部时间冻结，以及导入环境原有净空检查。

报告路径为 `docs/verification/refined-environments/geometry-motion.json`。缩略图另用 `RefinedEnvironmentReview.Thumbnails()` 在一次图形模式进程生成，避免在无图形检查或连续脚本重载期间启动渲染。实际 App 画面、动态和角色隔离由手机模拟器 UI 测试补充，验证结果由主流程记录。

普通 runtime 的 `environment` 对象新增兼容字段：

| 字段 | 语义 |
| --- | --- |
| `ambientNodes` | 背景声明的局部动态节点数，包含当前被摆设开关隐藏的节点 |
| `ambientTime` | 当前背景自己的活动时间，单位秒 |
| `ambientRunning` / `motionSuppressed` | 活动背景驱动是否启用，以及是否因暂停/失焦冻结 |
| `rendererCount` / `vertexCount` | 初始化时统计的整套资源预算，包含可隐藏装饰 |
| `clothOffset` / `swayDegrees` | 当帧可见帘布的最大位移（米）和植物转角（度） |

这些字段来自实际运行组件与网格，不是测试专用的虚构播放状态。没有动态增强层的旧包继续显示静态场景，字段自然为零。

## 实际画面复核补正

优可的真实会话截图揭示小院原始GLB地面没有TEXCOORD_0，换材质仍呈纯色；远景前的水平地面还形成生硬直线。宿主增强只克隆Floor网格，按环境米单位生成XZ UV、切换细缝低反差石材，并检查UV数量、两轴范围与有效顶面三角面积。远景前加合批低石沿和错落叶簇，全部位于角色净空外；结构层保留这些衔接，关闭可选摆设也不会重新暴露接缝。不改源GLB、角色或相机。重新生成、缩略图和两端导出后再次检查实际优可会话。
