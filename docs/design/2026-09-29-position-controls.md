# 位置与声音控制 · 0.44.0 / 65

## 用户操作

会话右上角放置轻透的15pt位置图标，44pt触区。轻点产生一次轻反馈，进入编辑；图标变为勾，再点结束。移除长按进入与渐强震动，正常聊天时拖动不会改变角色。

玻璃提示条宽最多268pt、高90pt，位于原聊天区中央，不为其重新取景。只有右上角的「恢复默认」占用点击区域；其余标题、说明和玻璃背景均穿透到模型。关闭使用提示条外的原入口，因而不会在条内再占一块手势区域。编辑期间聊天暂停滚动、内容淡出，结束后恢复。

单指旋转；两指距离控制比例，两指中心位移控制位置；手指数变化立即重设手势基准，防止加第二根手指时跳变。每次松手与关闭均自动保留最后状态。每账号、每角色仅存一项可选 `viewPose`，旧 `viewLibrary` 只用于迁移选中项，迁移后删除整个库。恢复默认也立即持久保存，没有方案列表或保存入口。

声音图标单击打开设置，无单击静音或长按特殊动作。设置保留总静音、朗读/音效/音乐开关及音量；三路控制放进同一紧凑分组，角色专属配乐改为菜单选择，默认窗口高420pt。

## 旋转修正

旧逻辑有两个耦合：绕人像包围盒中心旋转，而包围盒受头发/配件影响；每次旋转又调用缩放/位移，并按角度重新夹紧它们，造成屏幕上的横移、缩放与绕偏轴效果。

新轴心使用原作骨架的髋/颈中点，绑定时固定在角色局部坐标中，不随呼吸每帧漂移。旋转围绕经过缩放后的同一个身体轴心，单指路径完全不写比例或平移。遇屏幕边界仅收敛旋转角度；双指负责受约束的大小和位置。保留近景人像包围体、安全区、四边及弹性过渡检查；特别大的角度可能要先缩小或移向中央，不能靠自动挪动角色来强行转过去。

保留旧版本读取；新宿主必须搭配真实导出的 `inspectionGestureRevision=5`。没有改动模型网格、骨骼姿势或原作动画。

## 依据

触摸穿透采用UIKit实际命中视图白名单：[Apple hitTest](https://developer.apple.com/documentation/uikit/uiview/hittest(_:with:)) 与 [Apple QA1812](https://developer.apple.com/library/archive/qa/qa2013/qa1812.html)。旋转围绕偏离角色的点会同时改变根位置：[Unity RotateAround](https://docs.unity.com/en-us/engine/6000.0/script-reference/unityengine/transform/rotatearound)。本项目采用显式根变换数学来分离旋转、缩放和位移，并用骨架轴心不动的实际 TransformPoint 断言验收。
