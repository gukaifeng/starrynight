# 自然注视用户（v0.8.3）

目标：角色随取景方向和自身位置变化，在舒适范围内看向虚拟镜头；眼睛先跟上，头颈缓慢跟随。无需摄像头，也不采集用户面部。既有手势范围仍为左右20°，不放开无限旋转。

## 设计范围

| 部位／情况 | 当前范围与行为 |
| --- | --- |
| 头颈合计 | 左右50°，抬头22°，低头28°；斜向使用椭圆限制，不能同时达到两个轴的极限 |
| 眼球补偿 | 左右12°，向上8°，向下10°；左右眼分别指向同一个虚拟镜头 |
| 侧后方 | 相对上身65°内正常跟随，65–105°逐渐退出，105°外收回；跨过背面不会追转180° |
| 过高／过低 | 俯仰40–65°逐渐退出，65°外收回 |
| 鞠躬 | 让出注视，保留低头动作，结束后平滑找回用户 |
| 摇头 | 保留原动作幅度，眼球跟随减弱，避免“头在摇、眼睛焊死” |
| 无独立眼球的Luma | 用头部整体朝向完成注视 |

以上是本项目的保守动画设计值，不是医学活动度结论。极端角度优先自然，不能承诺所有姿态都与用户对视。

## 实现决策

- 沿用已有Legacy Animation，不迁移整个动画栈或引入新的运行包。参考Unity官方执行顺序与Multi-Aim轴／范围设计，使用轻量程序化叠加；每帧只更新头、颈和双眼的变换，无网格烘焙、射线或分配。
- 以动画后的上身为基准，校准不同角色的骨骼轴。机器人和初音骨骼轴近似标准；真人颈部自带倾角，不能直接将localEulerAngles置零。
- 眼睛使用更快的临界阻尼响应，头颈使用较慢响应。输入来自实际镜头位置，能够随缩放、弹层构图、身高和位移一起变化。头颈分担约25%／75%的纠正量。
- 应用顺序：原动作 → 语音头部微动作 → 注视 → 初音头发惯性／碰撞。下一帧先还原本层改动，避免未写动画关键帧的颈部／眼睛累积扭转。
- 真人源模型眼球原本只有头部蒙皮，新建左右眼球骨骼，保留现有眼球网格、纹理、材质和形态键；不额外增加渲染网格。初音使用原眼骨；Luma的发光眼面保持原造型。
- 真机／模拟器导出都标记gazeRevision=1；构建前拒绝不含该能力的旧导出。

## 验证方式

引擎检查：三角色静态侧向／背面／高低目标、所有动作（含360°转圈）、骨骼反复更新无累积、60与120Hz响应对齐；保存实际引擎渲染和测量结果。模拟器检查：真实拖动、精细取景、弹窗取消、头部点击、初音转圈和鞠躬、iPad横屏。

模拟器与离线动画检查不代表真机持续120FPS。角度限制不等于通用布料／头发碰撞保证，后续增加角色或动作要继续复查其蒙皮。
