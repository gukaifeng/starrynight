# 回复描写、灵感接话与用户消息翻译

## 完成内容

本次针对用户报告的连续重复笑意、嵌套括号、英文角色中文心声和灵感接话交互问题调整，客户端版本为 0.89.0（119）。服务端权威实现位于独立仓库 `../starrynight-server`，代码提交 `217df7d`，设计见该仓库 `docs/design/reply-asides-and-translation-2026-10-02.md`。

- 生成器、回复编译和预缓存取用共同检查近期非发音描写，去除相同/相近及同类笑意描述；实际表情与动作仍执行。提示要求新心理、自然停顿与语气符号。内部修订仅改变无效心声时保留正确台词主题。
- 英文角色与英语目标要求台词、心声、动态描写均为英文。经审查的资源语义映射英文说明，不给未知动作编造英文表现。
- 待机语音同样要求新心理，并允许选取已审查的模型外貌事实，不凭空杜撰事实、道具或动作。
- 客户端 `ReplyDisplayText` 读取旧消息时修复嵌套与未闭合括号，统一单层斜体和颜色。真实语音只读台词，新结构在服务端修订可识别的内嵌动作/心理描写。
- 灵感接话各项右侧增加小翻译按钮；用户消息同样可翻译，包括中文中有足量英文的混合消息。翻译后可切回原文。接话发送仍使用原始候选 ID 和内容，复用已准备的回答。
- 翻译复用现有百炼翻译通道及账户隔离缓存，校验真实消息或候选身份；翻译本身不进入对话上下文和语音。
- 灵感窗口添加窗口级轻量点击观察：点击任意外部区域，包括气泡、输入框、页签和工具按钮均关闭，原控件仍正常收到点击。拖动聊天和模型不会因为该观察器被截断。输入框点击不被关闭手势再次收起键盘。
