# 取景编辑与保存方案 · 0.43

- 保留一秒长按、轻弹性蓄力及渐强触觉；到时只打开编辑面板，原按压序列不改变姿态。之后单指转动、双指缩放及平移，松手保留草稿。
- 玻璃小卡居于原聊天区域中心，消息与输入暂时淡出；舞台相机不因面板改变。可操作模型、卡片和底栏；卡外点按不关闭，避免旋转操作误退出。提供明确关闭按钮。
- 卡片采用原生 iOS 26 Liquid Glass，旧系统用 material；遵守减少透明与减少动态效果。月白主题文字、圆角26、紧凑两行手势说明、同一行恢复/保存，横向方案小胶囊。保存自动命名，可删除，避免键盘占用角色舞台。
- 保存属于账号+角色记录的可选版本化字段，老档案兼容。松手不恢复；关闭/退出会话/后台放弃未保存草稿，回到已选保存方案，未选则默认。保存及选择方案成为新的已提交状态，重启后复用。原作者动画/相机/模型资产不修改。
- 约束基于当前实际相机、角色原始人像包围体及窗口安全区，使用全部八角点透视投影求可行缩放和位移。默认仍是既有半身会话构图，约束保护头部与上半身主体，不强制把腿部塞进画面。各尺寸/旋转后重新约束已保存方案，按归一化视口存位移；不使用机型列表。
- 验证：原作骨架不变、松手保持/关闭撤销、保存重进与账号角色隔离、不同手机尺寸与横竖屏的投影边界、真多指触摸、玻璃页面截图。真机可连接则安装，不阻塞模拟器开发。

原生效果依据：[Apple Liquid Glass 自定义视图](https://developer.apple.com/documentation/SwiftUI/Applying-Liquid-Glass-to-custom-views)。
