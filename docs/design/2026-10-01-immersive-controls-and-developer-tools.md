# 沉浸式展示、对话控件与开发者工具

版本 0.75.0（102），2026-10-01。沿用 11 个已打包角色、已有图片和音频，不调用收费生成模型，不修改 Unity 骨骼、材质、动画或默认取景。

## 用户侧界面

- 封面改为实际图像填满容器，使用已审查的头部范围决定焦点，取消左右暗色模糊补边和横向渐隐。短横幅在填满后无法同时容纳完整头饰时优先头部方向；资料图从 106 高的短条改为 1.2:1 横幅，圆形头像继续使用完整头部适配。加载背景使用相同铺满实现，只在底部文字区域保留纵向遮罩。
- 发现页压缩标题、分类、间距和精选。精选从 150 高大横幅改成可横滑的小条目；角色网格最小列宽 108、列距 8，iPhone 17 竖屏显示三列，其他宽度由网格自适应。原有搜索、筛选、排序和资料入口保留。
- 快速回复标题为“灵感回声”，面板宽度明确限定为容器宽减 48，最大 380，避免内容撑到左边缘。
- 录音浮层最大宽 360、内边距 12，保留波形和即时文字。下方两个目标区为取消和编辑：进入只高亮，退出撤销选择，松开后执行。普通松手发送、识别提前完成、网络失败保留文字、键盘草稿隔离仍用原来的状态机。取消丢弃这一段语音，不发送迟到识别结果。
- 输入切换符号分别为 18/19 点，点击热区仍为 44。声音窗口缩到 216 高，“朗读”改称“心声”，音乐行明确写“背景音乐”，曲名附在下方，两个滑块滑至零即静音。
- 角色名胶囊内分为独立的资料按钮和订阅区域。未订阅可一键订阅，已订阅为淡色文字；取消订阅在资料页操作。不因取消订阅强行退出当前会话，离开后再进入首页仍遵守已保存的订阅列表。

## 氛围浓淡

`CharacterProfile.atmosphereLevel` 为可选整数，0–4：关闭、轻盈、适中、浓郁、绚烂。缺失时由旧 `atmosphereEnabled` 迁移：旧 false 为 0，其他默认 2。新字段优先，仍写旧开关以便旧客户端理解关闭状态。设置随原有角色账户资料保存，`conversationProfile` 必须保留新值。

中档粒子基数从 34 提升到 110，并提高亮度、尺寸与环境光流的可见度；继续沿用各角色自己的颜色与效果配方。总量上限 180，低电量上限 96，静态辅助模式减少粒子并暂停移动。Canvas 不接管手势，也不逐粒子创建计时器。数量上限是实现约束，不代表已完成真机帧率或温控验收。

## 开发者页面与构建隔离

入口一：我的 → 设置 → 开发者页面，查看构建信息、角色列表及各角色检查页。

入口二：角色资料 → 角色开发者页面，内含 AI 设定检查、手动角色表现和资源能力摘要。手动表情动作按钮不再出现在聊天框或普通资料按钮行；AI、语音和场景驱动的自动表现继续使用原有路径。开发者子页使用当前窗口内渐变切换，保持统一标题及窗口高度。

开发工具使用 `STARRY_TEST_TOOLS` 编译条件；本地明确启用的 Release 构建仍可作为性能较好的开发安装包。正式分发使用：

```sh
bash scripts/build_device.sh --distribution --unsigned
# 实际签名归档前，生成不含工具的工程：
python3 scripts/generate_host.py --platform device --distribution
# 分发包构建完成后检查产物：
python3 scripts/check_distribution_app.py --platform device
```

`--distribution` 覆盖本机 TestTools.json 和环境变量，移除 Developer 目录、AIInspectionPanel 源引用及 ClientAIRules 私有资源；手动表现视图也经编译条件剔除。带工具的工程执行 Archive 会由构建脚本拒绝，提示重新生成分发工程。日常 `build_device.sh` 仍生成开发工程；正式发布的签名、渠道与凭证需要届时另行配置。

## AI 检查分区

原来的四个场景是请求预览场景，不是四套不同角色设定：人格、规则相同是正常的；上下文及请求应随场景改变。新的界面明确说明这一点。每个报告分区独立打开详情页，以角色、场景和分区 ID 确定页面身份，检查返回的角色与分区 ID 唯一性。空请求、耗时等运行记录用具体分区名称说明“暂无记录”，不再只有几个看起来一样的 `{}`。

报告仍保留完整原文、全部复制与分区复制。本机相处资料和 App 执行规则照常补入，服务端鉴权及账号/角色隔离不变。读取检查页不生成回复，不消耗 AI 用量。验证结果及实际问题见 [验收记录](../verification/immersive-controls/README.md)。
