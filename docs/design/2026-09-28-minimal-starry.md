# 星夜 v0.22 · 极简标志与清爽聊天

## 设计方向

对象是以精致3D角色为主体的陪伴软件，界面的任务是让人继续聊天。沿用 frontend-design 的设计与截图评审方法，这次把辨识度集中在一个单色星月标志，去掉围绕模型的重复提示和独立工具图标。

色板：夜底 `#101114`、月白 `#F1F2EE`、层面 `#1E2025`、次要文字 `#ABAEB9`、分隔线 `#3F444F`。页面标题保留 SF Rounded 半粗体，聊天正文用系统常规体；时间使用圆角等宽数字，避免控件跳宽。布局关系为「名字可点 → 角色全屏 → 历史渐隐 → 输入框 → 底栏」。

## 真正的矢量 Logo

弯月的开口给四芒星留下空间，仅两条封闭贝塞尔路径；无文字、光圈、渐变、纹理或位图嵌入。原稿可独立缩放、换色和交给其他设计工具。

- 深色透明标志：`assets/brand/starry-mark.svg`
- 浅色透明标志：`assets/brand/starry-mark-light.svg`
- 深色背景图标：`assets/brand/starry-app-icon.svg`
- App 内 BrandMark：PDF 矢量资源，并启用 `preserves-vector-representation`
- iOS 桌面图标：由同一几何导出1024px无透明PNG
- 重生成：`swift scripts/generate_starry_mark.swift /Users/gukaifeng/Documents/ios-app`

SVG 与 PDF 都由同一组路径生成，不是旧图描摹或在 SVG 里塞入 PNG。旧图保存在品牌归档目录，不再作为当前 App 的 Logo。

## 控件与动效

四个普通底栏图标统一放进26×26pt对齐框；较宽的对话图形为23pt，面积较饱满的圆形轮廓为21pt，按视觉重量补偿，全部使用同一笔画权重，选中状态由颜色表达。中间加号保持独立视觉层级，不添加文字。

回到最近使用 `chevron.down.2` 双下箭头：没有竖线、圆底或边框，独立浮层向下14pt，保持44pt点击范围。图形在4pt范围内缓慢上下运动并渐变亮度，出现时持续循环；开启“减弱动态效果”则静止。浮层不参与历史和输入框测量，点击行为仍是回到最后消息。

语音挂件与消息气泡从4pt间距缩至视觉贴近（边缘约1pt重叠），保留44pt点击范围，播放时以局部微光呼吸表达状态；不恢复音柱、进度条或额外状态条。

## 页面精简与功能边界

- 移除聊天中的“在这里，陪你聊一会儿”状态块与“离线语音已就绪”等状态行。
- 隐藏游客剩余轮数及附带的固定登录栏。五轮体验上限仍由原有会话层执行，需要继续对话时再进入登录。
- 顶部取消静音和独立定制图标，角色名字连同副标题构成无底色的点击区域，打开原有定制弹窗。
- 角色静音位于定制弹窗顶部，按角色持久化；开启时停止自动朗读，手动点击单条语音仍可播放。
- 原有离线声音引擎继续工作；删除界面里的“离线”文案不代表已经接入在线服务。网络对话和声音服务仍待后续接入。
- 错误提示保留在实际失败时显示，不用正常状态文字长期占据页面。Debug录音夹具入口仅在显式测试参数下出现，不进入Release界面。
