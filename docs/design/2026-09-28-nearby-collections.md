# 近伴：角色集合、游客体验与主题（0.19）

## 目标与视觉决策

优先 iPhone。打开即进入角色对话，角色是主体；发现负责高密度挑选，我的负责个人身份。名称改为常用字「近伴」，不再延续星字品牌；不据此宣称商标可注册。

默认深海：夜海 #070D17、内层 #111F2E、卡片 #16293D、浅海 #89CFF1、暖沙 #E7C8A4、文字 #EEF3F6。提供暖夜、松林、月白三组暗色预设，以及轻透/沉静两种表面样式。中文标题用系统圆体 semibold 26–28pt，正文系统字体 15–16pt，辅助 11–12pt。禁用滚动条，支持减少动态效果。

布局：聊天全幅 3D + 下半屏渐隐文字；发现固定搜索/筛选 + 两列紧凑卡片（头像约 48pt、名字、性格、短介绍、关注）；我的上部个人头像/账号/签名与真实统计，下部关注/作品切换，设置收纳账号、主题、关于和体验身份。空状态视觉中心上移。

标志取「两道相向的弧，之间留一束光」：暗海蓝底、浅蓝与暖白，表达靠近而不挤占彼此。去掉原来四处散落的星光装饰，集中在中间创建入口保留微光。审视后舍弃大面积插画封面和夸大的作品统计，给真实信息让位。

## 角色集合边界

CharacterCollections.json 是每个基础角色的集合清单：版本、模型引用、动作白名单、背景白名单、声音预设、音乐选项、默认项。资源可以显式引用相同不可变底层文件；选项属于各自集合，用户修改按 accountID + characterInstanceID 保存，不能跨集合按全局 ID 获取选项。创作角色保存集合快照；发布只输出设定与集合，绝不输出私聊和记忆。

选择、保存、预览都校验允许范围；旧记录的非法选项归一到该集合默认，不把旧全局音乐偏好复制给所有角色。现有两个原创音乐文件与单一离线中文 TTS 引擎复用，各集合绑定独立曲目/说话节奏预设，不声称已具备角色专属训练音色。后续音色模型、动作或场景由清单显式扩展。

## 游客和账号

首次游客直接进入默认初音角色；消息可用。安装级游客额度持久化，不随角色、历史清空、重启或退出账号重置。每次接受用户消息先持久化预留一轮（中断仍算，防止中断绕过），最多五轮；重答不新增额度但额度耗尽后需要登录。第五轮后显示温和登录入口，第六次发送被拦截，不截断第五段音频。登录切换时停止旧会话异步回调。

首次创建的账号承接游客记录并默认关注初始角色；已有账号只恢复自己的最近关注角色，不合并游客，不复活已取消的关注。关注为空时首页/消息均引导发现/创建；旧聊天仍保留在角色记录，重新关注可找回。

## 声音与主题

所有成功生成的回复默认交给离线朗读，不因为资源就绪检查竞态而跳过。聊天底部常驻小型喇叭静音按钮；静音立即取消正在合成/播放的声音，保存在当前角色，音乐另有控制。重新开启只朗读之后的回复。主题按设备偏好保存，不改变角色外观、背景或账号资料；全屏页面实底，半屏渐变保持渐进。

## 验证范围

资源越界拒绝、角色/账号音乐偏好隔离、旧档迁移、游客五轮持久化、新账号承接与旧账号空关注、消息跳转、本地多字段搜索、四组主题即时切换与重启、实际离线朗读与静音。仅 iPhone 模拟器与可连接的 iPhone 真机，不新增 iPad 验证。
