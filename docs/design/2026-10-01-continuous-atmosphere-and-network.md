# 0.79.0 连续氛围、消息左滑与联网依赖

## 连续氛围

用户将交互要求更新为无级调节，取代 0.78 的五个吸附档位。原生 UISlider 使用 0…1 连续值，没有刻度、吸附或跨档震动。面板显示百分比，零值为关闭。

新增可选 `CharacterProfile.atmosphereIntensity`，旧 `atmosphereLevel` 和 `atmosphereEnabled` 保留用于向后读取。旧档位分别映射到 0／0.25／0.5／0.75／1；效果倍率连续映射为 0／0.25／0.5／1／1.5，因此旧用户实际看到的浓淡保持不变，新用户默认仍为中间值。新字段优先，保留任意小数，不回写成整数档。模型打开时保留此个人偏好，角色之间隔离。

滑动过程只更新会话内存预览，不为每一帧复制／编码完整聊天档案。松手、取消触摸、离开页签、关闭窗口或进入后台时提交最终值；提交检查账号归属，避免切换账号后写入另一账户。VoiceOver 的无触摸调整直接提交。

粒子使用既有临界阻尼包络，从当前值与当前速度重新设定目标；连续快速拖动、反向或归零仍平滑过渡。粒子索引稳定，新增／减少通过透明度淡入淡出。低功耗预算、关闭后的绘制暂停及“减弱动态效果”继续保留。

## 消息与会话设置

消息现在仅**左滑**展开右侧“不显示／删除”，右滑不展开。继续使用并排布局、红色删除和确认期间保持展开；取消确认后再恢复。此次方向调整以本轮最新用户要求为准。

会话设置复用原生空白点击识别器，位置、声音、氛围页均支持窗口外点击关闭。排除设置窗口、右上角开关与底栏的命中区域。只有完整点击结束才关闭；位置编辑时的旋转、移动和缩放手势不关闭窗口，窗口内部调整也不触发关闭。未增加全屏触摸遮罩。

## 网络审计：为什么仍依赖 Mac

实际私有配置中的 AI origin 为 `http://yiyu.local:8766`，指向这台 Mac 上的 Python AI 服务。App 自己创建 URLSession 网络请求，没有禁用蜂窝网络的客户端配置；但 `.local` 是局域网发现地址，Mac 停机或手机离开该网络后，这个服务就不可达。

当前设备账户专用配置不存在，共用账户配置为 Mac loopback `http://127.0.0.1:8090`。生成脚本会正确地将此 loopback 配置排除在真机包外，避免错误请求手机自身。因此当前真机并没有独立的公网账户服务，不能把本机体验账号当作已上线的账户云同步。

AI 服务负责完整人格上下文、场景预备池、三条智能回复及预测、表演匹配、TTS／ASR 代理、检查和删除一致性。简单把 origin 改成百炼域名不能工作：星夜的 `/v1/conversations/...` 和百炼的原生 API 不是同一协议，也不会自动获得账户服务。

完全脱离 Mac 的两种路径：

1. **独立 HTTPS 后端**：将已有 Go 账户服务、Python AI worker、PostgreSQL／Redis 和私有状态部署到常在线环境。App 连接公网 origin；入口要支持 SSE 和 WebSocket。付费 API Key 留在服务端，当前功能结构保持。现有云部署边界见 [后端运行手册](../../backend/docs/runbook.md)。本次尚未获得独立服务器／公网端点，不能声称已完成公网部署。
2. **私人开发版直连百炼**：需要新增手机端编排、原生百炼 ASR/TTS 适配、私有凭证保管和各场景预备池；账户云同步仍需要独立后端。此路径不能只修改 URL，也不能将开发凭证加入公开仓库或正式分发包。

本轮已向用户询问上述架构选择，完成界面工作与验证期间不等待该选择。未凭空配置服务器、未将付费 Key 塞进 App，也未用依赖 Mac 的网络隧道冒充独立联网。网络依赖的去除仍待用户选择路径／提供部署目标，界面版本交付不代表此项已完成。
