# 星夜情绪、发声与全身表演标准 v1

2026-10-03。当前在册 16 个角色共享此标准，角色实际骨骼与表情分别解析；缺少部件时明确降级，不虚构资产。

## 官方模型能力

云端只读配置已确认使用 `qwen-audio-3.1-tts-flash`。官方文本控制标签 23 项、拟声 7 项，依据[阿里云实时语音合成文档](https://help.aliyun.com/zh/model-studio/realtime-tts-user-guide)。前者同时包含情感、语速、耳语及角色化声线，不能当成 23 种独立情绪。应用标准采用 28 种情绪、7 种风格、7 种拟声；每项 3 组，总共 126 组。自然、平静、开心、害羞等没有独立厂商标签的语义通过自然语言指令表达，不能称为厂商固定枚举。

脸部从原作校准的表情基类选择。缺少目标基类时，按明确的语义邻居链选择，再不支持则保持中性；不随便采用第一个 morph，不覆盖口型权重。身体使用每个角色的解剖轴和肘关节校准；手腕与十根手指近节有独立小幅强调。髋部重心、膝盖与脚踝由保持原作脚部接触的两骨 IK 驱动，接近伸直的膝盖自动减少额外重心位移，替换为胸肩动作。

耳朵、尾巴及今后出现的自定义分组只选择已声明、可随语音播放、非循环、非穿搭开关的原作动作。头发、衣服和饰物继续经过原作来源的弹簧与现有碰撞避让；不把所有饰物硬改成同一个摆动角度。没有专属动作时保留物理跟随，或者用头部/上身表达同一情绪。开发者面板的每一条列出该角色实际表情、原作配合、已支持通道与不可用部件。它从活跃角色请求实时解析，不能把另一角色的映射拿来冒充。

## 组合和时间线

每句单独持有情绪、发声风格、心理描写及可选拟声位置。身体主组合随机选择三者之一，同时排除最近实际身体组合及该类上次组合。风格是同一动作的修饰，拟声是短时的叠加，不重新启动整套模型。句子开始时从真实语音 PCM 回调触发表演；短句按语句时长收缩表演包络，仍保留准备、强调与恢复。模型静音时走同样的句子时间线。

表演曲线沿用 C2 五次平滑包络，首尾速度和加速度连续；身体、头和手臂有错相，原作完整姿势、用户模型操作和原作动作优先。衣物避碰保持共同的服装包络预算。新组合不修改角色根节点、取景、摄像机或用户位置。额外表演仍受原有“身体与表情组合”开关控制；旧 48 项动作实验与原作库保留。

完整段落的旧固定问候只有一段 PCM，内部句子位置是按文本长度估计，不是实际音素时间戳。普通逐句生成的开始有真实 PCM 回调；句内非零拟声位置亦为语义停顿的近似定位，不声称精确口型级同步。

## 逐句内容约束与缓存

新客户端通过 `emotion_contract: 1` 协商。每句（含首句、九种场景、固定问候、预准备和快捷接话）至少一条虚构角色的第一人称心理描写，放完整句前后，永不朗读。额外神态与环境可选，不能编造未执行动作。相邻两句标签不同，包括同一角色的上一轮最后一句；优先让 AI 自然生成转折，发布前用语义邻居归一化保证标签不同，而非随机在喜怒之间跳变。

保留老客户端和历史消息；旧 OSS 包通过宿主标准资源及问候元数据覆盖适配，无需重新下载角色模型。预缓存键包含标准版本，消耗缓存时再检查情绪连续性。为了保留秒回，已生成的 PCM 不被重新合成，开发检查中的 `voice_emotion` 留存实际合成标签，表现标签允许在语义相近的状态间微调；不能声称已经改变旧录音中的情绪。

## 开发者入口与扩展

可拖动开发者图标 → 情感表演标准。三类标签分开查看，逐项有三组播放按钮，匹配来自当前角色；预览不收费、不合成语音。原先“动作实验”与“角色表现”继续用于独立核对。生产版本隐藏检查界面，但标准和自动联动仍打包。映射只在打开检查页时传输，不把 42 项目录放进每个音量帧消息。构建导出戳含 `emotionPerformanceRevision: 1`，新宿主会拒绝链接不支持此标准的旧 Unity 导出。

标准 JSON 中稳定 ID 使用 `emotion.*`、`style.*`、`vocal.*`；后续新增条目/通道需推进标准修订并同步 Schema 与能力协商，不复用旧 ID 改语义，不要求重做已有角色包。角色资产只声明自身能力与解剖校准；宿主拥有编排、随机选取、冲突优先级、语音时间线和降级规则。服务端保存显式复制的合约快照，不跨仓库读取本机目录。

## 验证与限制

全 16 角色 × 126 组合，共 2,016 次完整数值采样，20,481,412 项断言通过；最大每帧骨骼增量 2.37°（60 Hz 采样），脚部误差小于 0.000202 m，新增衣物相交量在原有 1 mm 容差以内。另做 16 × 28 次情绪、呐喊风格及笑声并行的短句压力验证，最终 2,308,504 项断言通过（含连续风格与实际播放去重）。它们是姿态和曲线检查，不是手机 FPS、三角面全碰撞或模型音色听感测量。

服务端离线验证 375 项通过，4 项按原条件跳过，包含全部官方标签、48 个固定问候和全部九种场景。没有调用付费 AI，也没有调用图片生成；声线强度和各情绪的实际听感留给用户使用当前音色检查。模拟器、云端及真机安装结果另附最终验证记录。
