# 普通会话中的临时单指旋转

> v0.54.1 更新：聊天空白和消息上的横滑也支持临时旋转，纵向消息拖动保留原生滚动；最新分流规则见[聊天区域手势分流](2026-09-30-conversation-gesture-routing.md)。下文的“识别器只挂角色层”和“不从聊天启动”是最初版本的实现，已由新方案替代。

## 交互约定

没有打开右上角位置编辑时，也可以从可触及的角色表面开始单指拖动。左右偏转最多 ±18°，上下偏转最多 ±8°，最终俯仰遵守角色视图当前的安全范围（v0.54.0 按用户反馈将编辑上下限从 ±25° 扩大到 ±80°，普通临时旋转幅度保持不变）。手指移动超过 7 pt 后才识别为旋转，小幅点按继续走已有的角色点击路径。

松手以平滑阻尼回到当前保存的姿态，包括用户已设定的角度、大小和位置；不是一律重置为初始构图。普通拖动不会缩放、平移、打开弹窗或写入账户存档。第二指加入立即结束临时旋转并回弹，剩下的一指不会接着成为新的旋转。页面退出、失去焦点、禁用输入、切换角色也清理临时状态。

右上角位置编辑继续支持原来的单指自由水平旋转、有限俯仰，以及双指缩放和平移、保留最后状态、恢复默认。打开编辑会结束临时旋转，但不能把回弹中的角度存入永久位置。

## 关键实现

- `CharacterTouchSurface` 增加只接受一根手指的识别器，只挂在现有角色触摸层。聊天、输入框、胶囊和按钮保留自己的触摸路径。没有在整个界面上增加抢占聊天滚动的手势。
- 原生保留最初落指位置，Unity 使用已有 `HitDisplayedModel` 检查显示中模型的命中。拖过背景、后来才碰到模型不会启动旋转。
- `CharacterPreviewRotation` 只保存临时角度与阻尼速度。`CharacterInspectionRotation.ApplyFrame` 在已保存的位置上叠加角度，继续绕身体髋颈中点旋转。临时偏转不参与缩放/平移边界求解，不修改骨骼、原作动作或摄像机。
- 松手用 `Vector2.SmoothDamp` 回零；时间步长异常被拒绝，长帧限步，完成后精确归零。回弹中重新拖动从当前显示角度接续。
- 新桥接通道是 `nativeGesture` 的 `action: previewRotate`，状态为 `began / changed / ended / cancelled`，携带独立单调 `previewToken`。它不复用位置编辑的提交/结束事件，不进入 `rememberView` 的保存逻辑。
- 开始包含归一化的 `viewportX / viewportY`；`deltaX / deltaY` 是相对开始点、按视口大小归一化的总位移。此通道没有缩放或平移参数。角色/展示代次仍由已有桥接隔离。

Unity 状态增加 `previewRotationActive`、角度、峰值、开始与回弹计数，供真实触摸测试审查；没有逐帧向原生发送回执。`inspectionGestureRevision` 升到 **8**，原生构建前必须校验真实 Unity 导出版本，不能手改导出 stamp 冒充已更新。
