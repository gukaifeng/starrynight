# 简短星夜号、统一称呼管理与用户资料

客户端版本 0.90.0（120）；服务端实现提交 `0522e81`，在独立仓库 `../starrynight-server`，详见其 `docs/design/short-handles-profile-defaults-2026-10-02.md`。

## 完成内容

- 星夜号改为小写 `xy` + 分配序号：例如原 `XY100000000037` 迁移为 `xy37`，UUID 和所有账户数据关联不变。数据库全局序列及唯一约束共同保证跨 API 节点分配；保留旧号关联和注销号码，号码不复用，正常允许跳号。客户端不生成假注册号，未连接账户时显示“登录后分配”。
- 「我的 → 设置 → AI 对我的称呼」集中编辑全局默认称呼和每个可用角色的专属称呼。专属优先，留空回到全局；两者都空时自然称呼。返回保存，仅更新实际修改项，沿用账户隔离、角色偏好及现有云端同步，不添加第二份数据源。
- 用户个人主页与编辑资料都使用账户 `profile.bio`。新用户固定初始简介“在星夜，遇见温柔。”；既有自定义简介保留，不用作者宣传语填补个人简介。
- 默认头像只保留第三个“小星球”，删除猫/兔绘制分支及选项。旧默认引用兼容显示保留图案，云端迁移为 `starry-orbit-v1`，已上传照片保留。
- 我的主页面统一标题/数值 20、正文/栏目 14、辅助文字 12 的字号层次；头像编辑正文也统一，并沿用当前主题颜色。
- 本地头像选择采用 PhotoKit `.readWrite` 系统授权，支持 `.limited` 部分照片和 `.authorized` 全部照片。随后由 Apple PhotosPicker 选择单张图；拒绝/受限时提供系统设置入口。权限仅在点击选照片时请求，使用说明同步加入 Info.plist 和简繁英语言目录。
- 照片预览处理继续在后台生成裁剪缩略 JPEG；用户保存后才上传账户头像，不遍历相册。选择失败和拒绝不覆盖现有头像。

Apple 官方接口说明：[PHPhotoLibrary](https://developer.apple.com/documentation/photos/phphotolibrary)、[系统照片选择器](https://developer.apple.com/documentation/swiftui/view/photospicker%28ispresented%3Aselection%3Amatching%3Apreferreditemencoding%3Aphotolibrary%3A%29)。PhotosPicker 本身只交付用户选择的照片，不要求整库权限；本次显式 PhotoKit 授权用于用户指定的“部分/全部照片”选项，仍用系统选择器取得最终头像。
