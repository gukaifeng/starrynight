# 小伴 0.6 · 写实角色与空间

## 本轮交付范围

增加一个可定制的成年女性角色，保留 Luma、初音未来。角色使用真实人体比例、皮肤纹理、独立眼球、睫毛、眉毛、头发与服装网格。面容与体型参数改变实际三维几何；皮肤、虹膜、头发和衣服配色改变各自材质。服装随身体同参数变形，限制变化范围以减少穿模。

角色空间提供晴日客厅、柔光影棚、静夜三种预设；光源方位、高度、亮度和影子深浅独立调整，地面接收真实实时阴影。参数按角色保存，预览后可完成或取消，旧版本资料自动使用默认值。

交互入口：首页小夏卡片上的“定制”进入写实角色空间，角色上方保留真实模型，底部编辑面板分为面容、身形、造型、空间。现有角色也能使用空间设置。沿用小伴的绿、暖白、浅桃配色与隐藏滚动条，不增加自由拖拽和无限缩放。

## 资源与实现决策

- 查找技能后，Unity 操作继续使用 Unity Technologies 的官方 unity-cli skill。角色建模相关第三方 skill 未见优于实际工具文档的官方方案，不额外安装。
- 人体生成采用 MakeHuman Community / MPFB 2 的离线制作流程；Blender 官方 bpy 4.5.3 LTS 仅作为本机资产制作工具，不加入 iOS 运行时。模型与各项资产逐项记录授权，下载、制作脚本和出处保留。
- MPFB 的代码许可与输出网格、纹理许可分开；优先 CC0 系统资产和皮肤，使用 CC-BY 头发时保留作者与来源。参考：https://static.makehumancommunity.org/about/license.html 、https://static.makehumancommunity.org/assets/assetpacks.html 。
- 不采用不明授权的人物照片或直接冒用真人身份。默认角色为虚构成年女性。
- Unity URP 使用移动端实时材质、皮肤细节、透明裁剪发片和软阴影；不将离线渲染效果当成手机实际画面。保持120帧请求，实际设备性能以运行测量为准，不承诺每帧必达120。

## 必要验证

以构建成功、实际模型画面、参数对几何/光源生效、保存/取消/重开恢复为本轮核心验收。沿用用户要求控制验证范围，不重跑无关的全套历史测试。结果和遇到的关键问题追加到开发记录。
