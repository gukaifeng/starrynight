# 星夜 v0.21 · 语音挂件与聊天入口收整

目标：让角色与聊天占据注意力。沿用 frontend-design 的视觉检查流程，复用原生组件和已有声音引擎，不引入 UI 或搜索依赖；没有改动 Unity 模型与动作资源。

## 界面约定

- AI 回复外部、左上方显示独立语音挂件：23pt 可见胶囊，仅播放/停止图标与时长；44pt 触控范围留在上方，不覆盖正文。去除音柱、进度条及文字按钮。`8″` 表示8秒，`1′08″` 表示1分8秒；未完整合成时明确标记“约”，完整播放后显示已保存的音频实际时长，语速修改后重新估算。
- 挂件与所属消息一起经过聊天区透明蒙版。活动时仅切换停止图标和局部亮度，不添加大面积动态装饰。静音仍只关自动朗读，显式点挂件可播放一次，不更改偏好。
- 首页隐藏返回与动作菜单。静音移到角色名字右边，28pt 可见范围、44pt 点击范围，背景14%不透明；系统开启降低透明度时保持可读性。动作协议、聊天触发和触头互动继续可用。
- 底栏中心保留星轨加号，删除“创建”可见文字；辅助功能仍读“创建角色”。主题列表首位为月白，无已保存偏好时默认月白；升级不重置用户明确选择过的主题。
- 我的页无左上角标题。账户身份继续打开登录/账户，“关注／角色／聊过”的统计数字直接打开相应列表，删除重复菜单行；聊过按最近消息排序，包含当前账号可访问的历史角色。

## 本地搜索与定位

消息页搜索只检索当前账号实际保存的双方聊天文字，支持中文、大小写、重音及全半角归一，空白分隔词全部匹配。它不会拿角色名字充当聊天搜索，也不会查询整个多账号归档。先取 `CompanionStore.currentRecords`，再根据角色访问权限过滤，因此其他身份私有角色不会因知道 ID 而出现在结果里。

结果按消息时间倒序，展示角色、时间与关键词附近片段。点击结果打开对应角色并定位原消息；搜索目标可以早于默认最近60条。布局仍只测量目标附近最多60条，通过“回到最近”恢复默认窗口。既有磁盘每角色最多1000条的保留上限未变，本功能不声称可以找回已清理记录。普通标签切换仍保留原会话与画面，不产生新的模型加载。

当前数据规模使用 Foundation 文本匹配即可，不需要下载搜索模型或启动服务；未来数据库索引可替换 `ConversationSearch.find`，UI 使用稳定消息 UUID 定位。

## 验证重点

真实发送 → 本地搜索 → 命中片段 → 定位气泡 → 返回最近；旧消息窗口与账号隔离通过存储测试验证。界面检查覆盖播放/停止、实际时长缓存、静音位置、统计入口、月白默认顺序以及切标签保留会话。仅 iPhone，不添加 iPad 或帧率基准测试。
