# 会话入口、自由旋转和轻量声音面板

适用星夜 StarryNight 0.45.0 / build 66。按本轮用户要求更新 0.44 规则，保留琪宝、豆日向原作资产。

## 视觉与交互

- 右上位置按钮使用左侧角色胶囊实际布局中心对齐；保持小图标、高透明度与 44pt 点击区域。
- 位置提示条仍位于聊天区域中央、除恢复默认以外穿透触摸。先在透明状态下完成布局，再从原位下方 18pt 向上淡入；不再把首次零尺寸布局放入弹簧动画。减少动态效果时只淡入。关闭向下淡出。
- 声音面板内容高度从 420pt 收至 304pt。月白前景配深色半透明底；三行各 46pt，固定标签列、滑杆和等宽数字。底部仅保留当前角色配乐选择及一行音量说明。取消总静音和所有单项开关。
- 角色表现内容高度从 370pt 收至 302pt，分组胶囊更轻，双列选项最小高度 46pt。保留真实选中态、原作循环/一次动作说明与恢复默认。

## 声音与旧数据兼容

朗读、角色音效、背景音乐各自以 0…1 音量为唯一控制；0 静音，拉高即可播放。背景音乐切歌不能私自解除零音量。朗读降到 0 时立即停止当前语音；其他通道互不影响。保留录音暂停配乐、朗读压低配乐与后台暂停逻辑。

新增可选 `volumeControlsVersion`，仅一次把历史总静音/分项关闭转换为对应通道的 0 音量，随后清除隐藏开关约束。旧字段继续可解码，不清理聊天数据。偏好继续按账号/角色保存。角色音效是否有实际声音取决于原作包能力，本轮不新增音效资产。

## 主动问候

| 场景 | 行为 |
| --- | --- |
| App 进程启动，默认会话已实际显示 | 新关系介绍；已有关系按时间和历史欢迎回来；默认朗读 |
| 从发现/消息等切到另一个角色 | 新角色介绍；聊过的角色用重逢话术；默认朗读 |
| 当前角色在首页/消息/资料页之间返回 | 不重复问候 |
| 切后台再回前台 | 不视为重新启动，不追加问候 |
| 朗读音量 0 | 仍添加问候文本，尊重静音 |
| 加载被取消、角色尚未显示 | 不写入、不朗读 |

用实际 entry UUID 去重确认回调，而非“这段关系历史上已说过”阻断全部问候。沿用上下文话术、访客轮次独立统计、账号隔离、编辑时延迟与用户输入优先。

## 自由旋转

原生单指位移不再截断，横纵均按屏幕长度映射角度。Unity 不再限制 ±180° / ±20°，也不按屏幕边界截断角度；可以连续多圈并上下翻转。稳定身体中轴仍是旋转中心，单指操作不会自动移动或缩放角色。恢复默认使用等价最近角度，避免旋转多圈后复位又绕很多圈。

缩放与平移仍以角色原始立绘包围框和当前手机安全区限制；约束参照不随用户旋转变化，避免闭窗/重启后偷偷改变位置与大小。自由翻转后的外轮廓可能越过原始构图，这是取消角度限制的直接结果，不能再用自动平移、缩小来掩盖。用户可双指调整或恢复默认。

原生存储将角度按整圈折算为等价值，保留朝向而非圈数；例如 1125° 与 45° 相同，-810° 与 -90° 相同。运行时拖动角度连续，只有渲染四元数和持久化按 360° 等价处理。原作根变换每帧先还原，再叠加查看姿态；不改源骨骼、待机或动作曲线。

## 验证入口

- Unity `CharacterViewEditorReview.ReviewAndExportSimulator`：两角色 × 五种手机屏幕，真实根变换、多个完整横纵旋转、平移缩放限制、默认恢复、姿态重载和骨骼不变。
- iPhone XCTest：真实单/双指，玻璃穿透，控件对齐，采样 UIView presentation layer 验证向上淡入，持久化，三个音量和换曲，原作动作与问候入口。
- 结果与截图见 `docs/verification/conversation-refinement/README.md`。模拟器不是实机帧率或触觉验收。
