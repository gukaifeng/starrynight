# 小伴 0.17.0 / 30 · 自适应角色首页

## 设计目标

面向想与自己角色聊天的人，首页只有一个任务：快速找到想聊的角色。上一版把紧凑单卡固定在整屏中央，平板尤其显空；本次用窗口宽高共同决定行列与分页，保持固定页面、不纵向滚动。无需用户切换显示模式。

## 视觉方案与取舍

沿用松绿 #274A43、纸白 #F7F5F0、灰绿 #5B7168；角色卡使用浅桃 #F2DFD1、浅叶 #DEEADF、雾蓝 #D9E7ED、浅紫 #E5DFF0。姓名/标题为系统圆体中等字重，正文为常规系统体，辅助信息小一级。角色真实头像与定制缓存不变。

比较过等大的头像列表和横向大图画廊：前者过于通讯录化，后者仍浪费竖向空间。选用“有角色住在里面的小窗”：头像在柔和拱形窗内微微浮动、轻微倾转，背后有偏移色片；姓名、简短邀请与底部聊天入口形成清晰层次。把视觉变化集中在头像，不让整张卡一直跳动，不伪造在线状态、未读数量或情绪识别。

分页采用显式页位置与水平拖动：开始时判定方向，纵向擦动不翻页也不打开角色，轻点单独识别，滑动一次最多翻一页，越界有弱回弹。多页按钮的无障碍容器与各页分开，避免标识覆盖。

布局以可读卡片的最小宽高计算可见数量，在容纳人数相同时选择更平衡的卡片比例，避免三加一的孤立尾行；窄/矮窗口分页，分页指示放角色区上方且仅多页出现。旋转、打开后返回及异步头像刷新保留用户所在角色对应的页。

轻浮动只作用于可见首页头像；进入聊天、后台、系统减少动态效果时停止。轻点与页切换使用短缓和动画。头像采用真实模型近景，不为首页启动多个 Unity 渲染器，不增加模型下载或改动离线聊天。

## 验证重点

检查手机与平板横竖屏的实际截图、各角色入口、窗口内完整可点击、分页返回和头像缓存。布局计算覆盖不同尺寸、更多角色、字体放大，验证不漏人、不越界，不仅检查一张截图。
