# 0.67.0 / 93 · 角色氛围、快速建议与语音输入

实施日期：2026-09-30 至 2026-10-01。范围为当前发布名册四位角色：琪宝、豆日向、戚风、卡琳。原始 VRChat 资产保持不变。

## 功能与决策

| 要求 | 实现 |
| --- | --- |
| 快速预测三条用户回复 | 独立 `suggestions_model=qwen-turbo`，关闭思考，320 token 上限，最近八条有效消息各至多 600 字。三条建议按相对选择倾向排序；实际角色回答继续使用 `qwen-plus-character`，每个候选仍只准备一组，选择后才提交上下文 |
| 角色封面与头像 | 百炼 `qwen-image-3.0-pro`，使用原始 VRChat 图片和现有角色设定。四张 1536×2048 封面、四张 1024² 头像；封面供发现、资料与加载共用，头像替代启动时的重复截图生成 |
| 专属音乐 | 每个角色只保留一首，移除选曲界面，保留朗读/音乐音量。Fun-Music 实际返回 403 AccessDenied，用户确认邀测申请尚未获准，授权先用网上匹配曲风的音乐；当前四首为 CC0 录音，**不是本项目 AI 生成** |
| 场景 | 四张百炼生成的 2048² 空场景图，Unity aspect-fill、有限分层视差、ASTC 6×6；显示新背景时停用旧程序化房间。角色仍是真实 3D，保留其灯光和自阴影；插画不能接收实时地面投影，不声称完整三维场景 |
| 氛围粒子 | 原生 Canvas 前景层：萤光、晨光浮尘、花瓣、星尘，按角色配色、密度与场景绑定；默认开启，设置跟随角色档案；低电量降低更新率，减少动态效果偏好暂停运动 |
| 微信式输入 | 默认键盘，左侧切换按住说话，右侧内嵌智能回复；键盘 Send 提交，无常驻发送键。按住出现拱形录音区、波形与实时转写，松手发送；上滑停止采集并进入编辑，编辑确认后发送，原键盘草稿独立保留 |
| 录音与发送性能 | AVAudioSession、麦克风引擎 prepare/start、音乐解码准备移至串行工作队列。麦克风采集与 ASR 连接重叠，最多约四秒前置缓冲；消息立即进入内存，JSON 编码与原子写盘在串行后台执行 |
| 设备摇晃 | Core Motion 40 Hz，去重力加速度与角速度共同判断，双向冲量、防抖、12 秒冷却；复用已有真实 AI 摇晃缓存，不增加固定台词。退出对话、后台、录音、位置编辑和弹窗期间不触发 |
| 手机和平板 | 同一 Universal App，复用设备自适应构图；iPhone 17 与 iPad Pro 11 英寸 M4 的竖屏、左右横屏、键盘、声音面板、四角色切换与资料页面纳入实际 XCTest |

## 模型选择与用量

采用用户提供的[百炼 CLI](https://bailian.aliyun.com/cli/install.md)官方技能，安装 `bl 2.1.0` 并核对[模型市场](https://bailian.console.aliyun.com/cn-beijing/model/market)。使用本地 `bailian-model-recommend`、`bailian-gen`、`bailian-docs-llm-wiki`；界面采用 frontend-design 指引，Unity 操作沿用项目 unity-cli 技能。

两个相同上下文各比较一次，六次付费小请求、共 2,538 token，三模型均返回三条有效结构化建议：

| 模型 | 两次耗时 | 平均 |
| --- | --- | --- |
| Qwen-Plus-Character | 2,598 / 2,463 ms | 2,530.5 ms |
| Qwen-Flash | 906 / 1,096 ms | 1,001 ms |
| Qwen-Turbo | 907 / 855 ms | 881 ms |

预测任务选 Turbo，约比该小样本的原任务模型快 65%；样本不能用于 p95 或稳定延迟保证。预测不是角色扮演，因此不复用完整表现目录和角色长提示。模型名进入请求及会话缓存键，切换配置不会串用错误模型缓存。其他 AI 对话仍使用完整上下文和原角色设定。

语音识别继续使用已接入的 `fun-asr-realtime`。一次 3.453 秒中文音频实测：133 ms 就绪，606 ms 首次非空文字，3,821 ms 完整结果；这是网关到百炼的实时音频测试，**不是手机按下至发声的端到端延迟**。

图像实际 17 次调用：首批 12 张，重做四张空背景，一张封面去除不应出现的文字。音乐只调用一次确认权限，403 后未轮询重试；未重新设计付费音色。开发工具默认只打印方案，只有 `--generate` 才收费，完成结果按指纹复用，失败/状态不明确需显式 `--retry-failed`。

## 错误处理与兼容

- 参考图编辑背景会保留巨大人物，首批背景未使用。改为从角色场景、配色提取纯环境文字生成并显式排除人物；运行时只叠加真正的 3D 角色。
- 戚风首批封面出现无关文字，单独进行百炼编辑删除，原输出与修订记录保留。没有使用本地绘图冒充 AI 生成。
- Metal 截屏发现背景上下颠倒，背景 shader 按 `UNITY_UV_STARTS_AT_TOP` 翻转 UV，两平台重新导出并查看实际截图。
- 一次 Unity 图形导出在 `DOTSInstancingMetadata/SRPBatcherShaderData` 崩溃。确认 Setup、资源生成与校验已完成后，使用已有 `ExportPreparedSimulator/Device` 的无图形恢复路径；完整 C# 与资源仍编译，运行时 Metal 未关闭。首次恢复项目不能跳过 Setup。
- 初次录音编辑 UI 找不到文本框，原因是 SwiftUI 父级 accessibility identifier 覆盖子标识；删除父级覆盖、给 UIKit 输入框独立 ID 后，实际编辑与发送通过。
- 声音操作异步后用修订号约束迟到任务，避免角色 A 音乐在角色 B 播放。录音取消、快速松手、权限拒绝、后台、超时分别清理任务；超时已有文字进入编辑区，不自动发送残缺文本。
- `atmosphereEnabled` 为可选档案字段，旧数据默认开启，既有 Go JSON 同步可携带。排队写入与同步读取共用串行队列，后台等待刷盘；磁盘失败保留内存记录并提示。
- 首轮 iPhone 综合 UI 在横屏回竖屏后进入子页失败；保留录像与失败 xcresult，加入关闭路径诊断后同流程通过，没有删掉失败断言。最终结果另列，不把初次失败改写为成功。
- 横屏语音编辑附加验证发现：键盘压缩高度时切换了文本框所在分支，导致焦点丢失。编辑区现在固定在同一结构中，空间不足时将发送/取消放到文字右侧，保持输入法组合文字与焦点；窄高度使用浅拱轮廓，避免内容伸出玻璃背景。

- 最终 `Media-20261001-Audio-Suggestions` 两条测试、24.667 秒、0 失败，覆盖音频线程/缓存播放和输入框内智能回复按钮及建议区位置。
- 真机 Release 构建和严格签名校验通过，包内设备族为 iPhone/iPad。通过同一网络成功安装到 iPhone 17 和 iPad Pro 11 英寸 M4，两台均读回 0.67.0 / 93。自动启动均被设备锁屏阻止，因此安装成功不记为真机交互验收；解锁后可手动打开「星夜」。最终安装、版本与签名证据汇总于 `.local/checks/atmosphere/delivery.json`。

本轮没有实体设备长时间 60/120 FPS、真实手持摇晃或真实麦克风噪声场景验收，不把模拟器布局、数值门限与服务端 ASR 测试当作这些结论。新图片、音乐随包离线可用；真实对话/转写仍需既有联网 AI 网关，图片生成密钥不进 App。
