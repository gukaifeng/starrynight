# 静赏、随速拖转与口语情绪（0.82.0 / 110）

本次承接 0.81 的界面语言、气泡翻译和持久语音缓存，完成普通会话拖转扩展、静赏模式、百炼专用翻译接入及文字/声音/表情的一致性。iPhone 17 已安装并读回 0.82.0（110）。没有更换角色模型、音色或增加付费媒体生成。

## 普通会话拖转

- 未打开位置编辑器时，单指水平临时转动范围从 ±18° 扩大到 **±540°**，即从当前保存视角向任一侧最多转一圈半；俯仰从 ±8° 调到 **±14°**。原有双指临时缩放仍为 ±5%，不允许在此模式移动角色。
- UIKit 读取触点时间戳，以每秒跨越的屏幕宽度归一化速度。45 ms 的速度平滑消除采样抖动。桥接新增可选 `previewSpeed`；旧消息未提供时按零速度处理。
- Unity 按每次采样的位移增量积分，基础为 300°/屏宽，速度增益平滑从 1 提高到 2.8。每秒 0.15 至 2 屏宽之间渐变；不会因突然加速而重新缩放已经转过的角度。到边界后反向拖动立即响应。
- 这是保存视角上的临时偏移，不进入持久位置、自动取景补偿或缩放计算。围绕现有身体中心旋转，不随转动挪动中心。
- 松手将当前偏移映射到等价的最短角度，再用 0.28 秒平滑阻尼回正。映射不改变画面朝向，避免转过一圈半后反向倒转一圈半。重新按下会清除回正速度，避免接手时反弹。
- 摇晃反应仍统计手指实际移动距离和往返方向，沿用原触发强度基准。单向观看不会被当成来回摇晃；旋转范围增大也不会让撒娇/生气更难触发。独立位置编辑器的无限水平旋转、±80°俯仰和持久缩放保持原协议。

## 静赏

入口在右上角会话选项旁，以小图标加「静赏」显示；启用后变为「聊天」。使用现有低透明度主题、44 pt 点击高度和简繁英本地化。

切换会淡出聊天记录、输入框及对应渐变遮罩，保留角色、背景、顶部身份和底栏。采用现有 0.42 秒缓动/减少动态效果策略，不改变角色位置、大小或摄像机。再次点击回到聊天。

同一个聊天承载控制器及会话保持存活，因此草稿、记录位置、语音播放和正在生成的回复不因视觉切换重建。切换时关闭键盘、快捷回复并取消正在进行的录音，避免隐藏输入区继续录音。隐藏聊天的命中区域也关闭，防止看不见的气泡继续截获模型手势。独立位置编辑模式同样允许点击静赏按钮。

静赏是当前会话界面的临时状态。变更角色后恢复聊天；不写入角色设置或账户偏好。此功能不将临时拖转变成持久姿态，想保留背面角度仍使用右上角位置编辑。

## 专用翻译和服务恢复

查阅百炼官方 [Qwen-MT API](https://help.aliyun.com/zh/model-studio/qwen-mt-api) 与[机器翻译说明](https://help.aliyun.com/zh/model-studio/machine-translation/)，选择 `qwen-mt-flash` 作为按需跨语言翻译首选。配置增加 `translation_model`，现有安装不用重填 Key。

专用模型使用一条 user 源文和 `translation_options`，`source_lang=auto`；目标分别是 `Chinese`、`Traditional Chinese`、`English`。使用英文 domains 提示保留口语和语气，不发送聊天 system 消息、JSON Schema 或不受支持的思考开关。

应用负责结构，模型负责翻译文字：

1. 保留原有消息所有权、源文核对、长度上限、同消息并发合并和完整译文缓存。
2. 将台词、心声、旁白的每个非空段落单独翻译，保存原 ID、kind、顺序、空白和换行。请求内相同源段落去重，总段落最多 64，全服务最多 4 段并行，初次成功探测后不把剩余段落串行化。
3. 成功的段落单独缓存；同一消息部分失败后再次翻译时不重复支付已经完成的段落。完整结果仍以源文指纹和目标语言缓存。消息删除同时清理这些记录，晚到结果再次检查消息存在。
4. 拒绝截断、不完整或空译文，保留原文。超时或网络故障不自动改用另一个付费模型。原设备简繁转换和已有完整语音缓存继续有效。

只有专用模型明确返回 `AccessDenied.Unpurchased` 或 `ModelNotFound` 时才允许临时调用原有快速模型，后者采用 JSON 约束但不进行付费格式重试。首次权限探测在并行段落之间合并。

若只有 MT 不可用、快速模型可用，一小时后在下一次请求重新探测 MT；若两个模型都被认证/权限拒绝，开发者状态显示无可用提供方，将重探间隔缩短为 30 秒后的下一次用户请求。**没有定时付费探测**。续费后优先尝试专用模型，不需要重新配置 App。开发者检查页面新增翻译服务状态、专用/建议模型名称及完整翻译执行规则。

本轮真实请求中，MT 和原角色对话/快速模型均返回 403 `AccessDenied.Unpurchased`。用户随后确认账户欠费、正在准备续费。不能据此断言某个模型单独没有开通，也不能把错误归因于手机权限。本轮停止追加付费验证；上述权限恢复路径通过假 HTTP 提供方验证，**专用模型实际翻译质量和续费后的真实链路尚待验证**。

## 文字、发音与表情一致性

核心台词规划和完整规划共享新的口语节奏要求：根据语境自然选择 0 至 2 处省略号、语气词、问句、轻短波浪号或欲言又止。可有「嗯……」「emmm……」「诶？」等，英语角色使用自然英文表达。它们是写作规则示例，不是本地固定台词；不强制每轮使用，不连续套同一开头，也不因增加语气而拉长日常回复。

输出通过已有 typed speech 元数据携带迟疑、温柔、轻柔、打趣等语气。保留现有 `qwen-audio-3.1-tts-flash` 和角色独立音色，按[官方 TTS 能力说明](https://help.aliyun.com/zh/model-studio/tts-model)使用原有指令/情绪/非语言事件接口。TTS 输入保留标点；仅语音侧把独立的 emmmm/hmmmm/ummm 转成适合中英文的短哼声，避免逐字母朗读。显示文字不改，mm 单位和普通英文单词不改。

声音指令说明省略号作短停顿、疑问语调和自然语气词，不读标点名称，不增加台词。舞台说明和心理活动仍不进 TTS。同一次轻笑不得既写「嘿嘿」又重复插入 giggle。

表演编排从语气选择角色实际支持的表现：迟疑偏思考，打趣偏俏皮笑，温柔偏浅笑；难过、惊讶、严肃、担心保留自身情绪。较长的迟疑段落可以后续转浅笑，按现有错开时序规则输出。卡琳和戚风没有相同的思考资源时，用其支持的困惑/浅笑回退；不合成新骨骼动画。编排仍与核心回复并行，不让表演阻塞发声。

未说出的预缓存上下文版本升至 4，淘汰旧规则生成的候选。已经说过的记录、完整音频与用户记忆保留。本轮因欠费没有合成新的声音，不能将规则测试写成实际听感验收。
