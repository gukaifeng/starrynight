# 普通模式旋转幅度微调（0.83.1 / 112）

用户在 0.83.0 体验后要求普通单指旋转的上下幅度更大、左右幅度更小。本次覆盖上一版的幅度参数，沿用已有手势、边缘映射、限速与松手恢复机制。

| 参数 | 0.83.0 | 0.83.1 |
| --- | --- | --- |
| 普通水平偏移上限 | ±180° | ±120° |
| 普通俯仰偏移上限 | ±14° | ±24° |
| 纵向手指位移响应 | 每屏高 65° | 每屏高 90° |

提高纵向响应是为了让相同手指位移也能看到更明显的上下转动，而不只是把难以触及的上限放大。水平仍以落点到对应屏幕边缘的距离映射，滑到边缘现在达到 120°，不再是背面 180°。最大角速度保持 300°/秒，现有平滑跟随、松手恢复、预览不写入保存姿态、±5% 捏扯和晃动反应判定保持原机制；精细调整模式未改动。
