# 星夜：沉浸式角色陪伴改版

## 目标与设计取舍

打开应用就回到上一次关注角色的对话。角色占据舞台，导航和聊天退到深色半透明的边缘。发现是一间角色展厅，消息是自己的对话，不再把角色选择当作首页。

新名称：星夜（星 9 画、夜 8 画，常用字）。保留现有 bundle identifier、沙盒及登录键，显示名称和图标更新，不删除用户档案。

配色：#080A12 夜幕、#151825 浮层、#24223B 紫色表面、#B6A1FF 星光、#E9BBCD 暖粉、#F3F0FA 正文。次级文字 #A4A4BD。使用系统圆体标题和系统正文，中文的可读性优先。标题 28/22，正文 15/17，标签 11/12。

```
首页：    角色姓名 / 定制         消息：最近对话      发现：星夜 / 角色展厅
         全屏 3D 舞台                头像/预览/时间         自适应角色卡
         从透明到夜色的对话区          已关注与历史           关注/进入对话
         精简输入框
         首页  消息  [星光 +]  发现  我的
```

视觉签名：一圈不闭合的轨道围绕四角星，作为品牌图标及创建入口；低亮度星点只在页面背景，避免遮挡模型和文字。有限弹性、渐隐切换；减少动态效果设置下停用循环动效。没有虚构粉丝数、在线数、点赞数。

## 数据边界

- 模型底座（runtimeID）与角色实例（id）分离：多个角色可使用同一模型，外观、聊天和头像独立。
- 模型包和桥接协议保持原格式；发给 Unity 的角色 ID 始终是底座 ID。
- 本地目录单独保存关注、最近角色、自建角色、可见性和发布快照；现有聊天存档继续读取，默认体验账号不改历史键。其他体验身份使用命名空间。
- 首次使用关注一个默认角色；取消所有关注后显示空状态，不能每次启动自动补回。
- 发布是本机市场模拟。界面写明没有云同步，其他本机体验身份可看到公开快照，私有角色不进入其他身份的发现页。未来服务端替换目录存储，保留角色 ID 和快照语义。
- 聊天历史保留，即使取消关注；从历史重新续聊会恢复关注。

## 风险与验证重点

两个 UIWindow（原生、Unity）都使用同一底栏，切页须等 Unity 淡出完成再打开新的角色；不能启动两个会话。键盘弹出隐藏底栏，输入框不被遮挡。横屏/iPad 使用可用宽度布局。关注、私有/公开、账号切换、历史和冷启动恢复需要落盘测试。静态截图检查黑色系、角色识别度、半透明聊天和底栏间距。


## 截图审阅后的调整

iPhone 初版发现卡偏高，第二排按钮接近底栏；收紧头像、卡片内部空白与介绍高度，保留 44 pt 操作区域。聊天窗口底栏原先依赖安全区导致横屏像悬浮色块，改为全屏宽底色及独立底部安全区内边距。统一登录主按钮使用深色字以提升淡紫底上的对比度。夜景保持模型原材质和光影，已有用户选择的房间不强制替换。没有用新生成的图片冒充 3D 角色头像，头像仍来自实际模型渲染缓存。
