## 旋转问题与修复

旧单指输入同时调用旋转和变换求解，边界按角度改变位置和缩放；轴心使用受头发/配件影响的人像包围盒中心。改为身体髋颈中点的固定局部轴心，按当前比例映射后保持同一个世界轴心；单指只更改角度，到边界停止，不用自动平移/缩放补偿。

实际回归还发现两处隐藏耦合：

1. 布局更新可能在根变换已经应用后发生；若从此时的Transform重算身体轴心，会把用户变换重复带入。应用视图变换期间保留作者轴心，恢复原根后才更新。
2. 旧人像只裁了整身包围盒的Y，仍把尾巴的深度放在头顶高度。琪宝原包围盒深度约0.96m，这会把尚未出屏的转身提前挡住。绑定时一次性烘焙可见原网格，仅从人像高度和横向范围内的顶点计算深度并留余量；缓存结果，不逐帧烘焙。

默认构图从第一帧就提供10%的距离余量和最多5%屏高的头顶余量，面板开关不再变更构图。尝试对所有转身角度一开始都预留完整包围盒，会让近景主体缩得过小，最终采用保留近景、按当前位置收敛角度的方式。范围过大时需先缩小/移向中央，不能以角度操作暗改位置。沿用±180°/±20°硬限制、屏幕投影范围及平滑过渡；静态约束覆盖人像主体，腿部和原作大姿态不保证完整入镜。
