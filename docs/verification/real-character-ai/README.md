# 真实角色 AI 验收 · 0.48.0 / build 69

2026-09-30。对应[实施设计与本机运维](../../design/2026-09-30-real-character-ai.md)、[角色 AI 表演标准](../../character-standard/08-ai-performance-standard.md)。范围是用户提供 v4.3 方案的真实对话、识别、音色、朗读和现有模型表演链路。没有用测试回复代替百炼结果；测试替身仅在后端测试目录中使用。

## 交付内容

- 生产代码删除关键词回复库、固定问候、预写故事分支及旧离线语音桥接、模型打包和本机语音服务脚本。新安装包不再包含 `LocalDialogue.json`、`VoiceModels` 或旧推理框架。历史设计文档保留，标明当时状态。
- 旧测试聊天先备份再迁移至 schema 2；保留角色配置、手动记忆、音乐、取景和订阅等资料。新回复标记 `cloud-v1`，AI 剧本和实测语音时长随消息持久化。
- 两角色共用编排协议、分别持有人设/状态/记忆/原创声音。琪宝轻柔圆润、豆日向清亮活泼；各创建一次音色并保留预览、voice_id 和角色绑定。
- 用户文字与实时语音最终稿进入同一后端；最近上下文、确认后的长期记忆、关系及情绪进入模型请求。台词、虚构心声、受实际资源约束的旁白分别呈现，只有台词和声音事件参与合成。
- 表演按角色可用资源白名单解析，临时表情/手势结束后恢复原选择。语音口型读取实际输出混音器，缓存播放不因网络分片到达时间提前张嘴。
- 流式文本和语音、缓存重播、取消、切角色、后台中断、错误提示、主动问候、有限前台空闲主动行为已接入。无法连接或结构校验失败时提示错误，不返回模拟答案。
- 后端部署到 macOS Application Support，通过 LaunchAgent 自动运行。模型 Key 和管理凭证只在服务端；App 仅带独立的开发网关连接凭证。

## 错误与处理

1. **模型结构不稳定**：中文beat编号、字符串心声及`playful → happy`等已知语义同义词在本地规范化，避免为这些表示差异付费重试。真正的递归嵌套字段仍拒绝；增加结构范例和独立speech_capability，最多一次低随机度纠正。`JSON Object`不是严格Schema输出，不能宣称消除了所有上游格式错误。
2. **旁白编造动作**：模型曾用合法手势引用描述递食物，也曾在literary里编造倚窗、光照和食物。performed不仅核对引用，还核对效果原句；literary改为只允许交谈节奏/片刻停顿的限定词汇，环境事实能力未建立前不开放任意场景描述。最后这项收紧使用本地反例回归，未为旁白再次付费采样；截图中的更早试验消息不代表新的允许范围。
3. **音频SSE与代理**：按多行SSE事件聚合解析，处理保活；系统代理需要python-socks，两次连接前失败确认没有发出任务，账本记为not_sent并释放预留。
4. **Swift6音频线程**：混音器tap在MainActor中创建导致后台音频线程触发隔离断言。回调改为nonisolated工厂，仅把Float音量送回主线程；通过真实播放器测试验证。崩溃中断的TTS保守计入已尝试请求，没有把不确定费用算成免费。
5. **UI与内容**：嵌套心声布局压缩正文，改为台词优先和自然文本高度；心声里“回复策略/遵守设定”等元叙述直接省略，旧持久化记录同样过滤，不生成替代假心声。
6. **运行环境**：launchd从Documents内的venv启动停在文件打开，迁到Application Support并共享同一费用账本；没有调整系统隐私权限。独立macOS Swift测试被SIGKILL，相关契约移到iOS模拟器实际执行。

## 费用和证据

Voice Design严格只调用2次；ASR测试总长9.592秒。模型请求按上游调用计数，一次有声回复通常有2次脑模型和每beat一次TTS，不能把一次对话说成一次调用。结构纠正和中断请求也保守计入用量。最终汇总保存在本机私有运行目录的`data/verification-summary.json`，实际扣费以百炼账单为准，没有读取或推测账户余额。

## 本轮边界

当前是可运行的本机开发后端，手机需与Mac同一网络且Mac不睡眠。独立云服务器、正式账户鉴权、跨设备同步、线上账单与运营监控尚未部署。音色管理采用开发管理接口，当前已绑定两角色，没有上线面向用户的付费重新设计入口。

角色模型的长期人格稳定性、所有声音事件的主观听感、主动行为在长时间真实聊天中的打扰程度，以及文档里的亚秒级识别/首音延迟目标，需要后续专门评估。没有宣称这些质量和性能目标都已验收，也未新增iPad或实体设备持续帧率测试。
