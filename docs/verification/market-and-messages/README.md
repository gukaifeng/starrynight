## 交互与数据决策

### 角色旋转

- 水平旋转保持连续、不限圈数；垂直角度限制在默认位置上下 **25°**。垂直灵敏度从完整归一化拖动对应 360° 改为 90°，避免轻微上下手势立即翻转。
- Unity 运行时 `inspectionGestureRevision` 升到 **7**。所有目标赋值路径都会规范化俯仰，包括仅旋转、跳过投影限制的路径。身体中心旋转、平滑响应、位置与缩放边界继续使用现有实现。
- Swift 存档也采用相同的 ±25° 规则。旧角度先化为等价角，再限制俯仰；如 720° 恢复到 0°，倒置角度进入最近的允许范围。水平存档可保存等价的单圈角度，不限制用户继续转动。
- 导出检查提高到 revision 7，防止宿主已更新而仍链接旧 Unity 旋转实现。没有修改原角色骨骼、动画或源资产。

### 消息「不显示」

消息行左滑显示「不显示」，不启用整行快速划过触发；VoiceOver 提供同名操作。操作后显示撤销入口；消息页的「不显示的对话」可逐项恢复。

状态以 `CharacterLibraryAccount.hiddenConversations[characterID] = hiddenAt` 保存，按账号隔离。它与聊天存档、订阅、当前角色分开，旧账号缺少该字段时按空集合读取，不需要清空或重建数据。

| 情况 | 行为 |
| --- | --- |
| 隐藏某个会话、随后重启 | 记录与订阅保留，消息行仍隐藏 |
| 启动或切回「对话」自动恢复上次角色 | 自动恢复页面本身不清除隐藏标记 |
| 从资料或搜索明确打开该角色 | 恢复其消息行，旧记录仍在 |
| 出现时间晚于隐藏时间的新消息 | 该消息行重新显示；新的主动问候也属于新消息 |
| 点击撤销或「恢复显示」 | 只移除隐藏状态 |
| 搜索本地记录 | 隐藏会话仍可搜索，点结果可进入对应消息 |

未来接入远程聊天记录时，列表可见性应继续作为用户、角色维度的独立元数据同步；「不显示」不能映射成删除服务器会话或消息。当前未实现跨设备同步。

### 发现页商城与共享搜索

沿用默认月白深色主题和圆形头像，不增加整屏加载层。顶部为统一搜索框、精选／全部／创作者入口和筛选；精选显示一张横向封面，随后是分类及紧凑双列卡片。卡片保留封面、名字、简短介绍、作者及 3D 标记，点击进入角色资料，再从资料开始对话。没有虚构销量、评价、热度或价格，也未增加独立作者栏目。

- 两页共用 `CatalogSearchField`：**44pt 高、左右 24pt 页面边距、14pt 字号、14pt 圆角**。清除输入与键盘收起方式一致；搜索语义各自保留，消息查聊天记录，发现查名字、设定、作者及分类。
- 目录可按分类、已订阅、关注作者的作品筛选，按推荐、最近更新或名称排序。推荐来自本地编排顺序，不声称运行个性化推荐算法。
- 精选、无搜索结果、没有创作者作品均有对应状态与操作；账号切换清除临时搜索、筛选及打开的资料页。
- `CharacterMarketItem` 将公开展示信息与私有聊天、个人取景分开。内置角色分类与精选顺序来自 `MarketplaceCatalog.json`。本地公开作品出现在目录；私有创建即使归当前账号所有，也只在「我的」管理，不混入商城。
- 当前目录数据、创作发布与账号间可见性都是本机原型。后续服务器目录仍需实现鉴权、分页、索引搜索、资源下载和真实发布服务；本轮完成的是页面与可运行的本地行为，并非远程商城已经上线。

本轮主要界面设计使用 `frontend-design` 技能，Unity 操作使用项目 [unity-cli 技能](../../../.agents/skills/unity-cli/SKILL.md)。没有引入新第三方依赖。
