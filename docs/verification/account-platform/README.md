## 关键故障与处理

1. Homebrew 非 TTY 安装被自己的解压子进程阻塞；仅结束本轮产生的进程，再用 TTY 完成。没有动用户其他服务。
2. 默认 Go 模块代理在本机不可达，改用 goproxy.cn 下载且保留校验；固定版本在 go.mod/go.sum。
3. 第一次真实注册出现 503，根因为 `pgx.QueryExecModeExec` 下 map 的 JSONB 编码推断失败；在新连接注册 map → JSONB 并用 json.RawMessage 写变更事件，之后真实集成测试通过。
4. CharacterLibrary 在同一个字典上交叠读取和写入导致 Swift 编译失败；改为局部账户副本修改后回写。
5. 修正同步的三方比较：原版本回执不能覆盖未发送的本机修改；网络等待期间产生的变化要纳入；null 删除后规范化已知可选字段，避免不断重传；批量保存失败时回滚并不推进 cursor。
6. 后半程终端进入受限权限配置，本机 TCP、CoreSimulator、Swift 插件受限。保留旧数据库、PID、缓存和用户记录，未用删除共享内存、禁用宏沙箱或修改系统权限来绕过。
