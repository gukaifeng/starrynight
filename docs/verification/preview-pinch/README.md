# 0.62 普通会话双指轻捏

2026-09-30，StarryNight **0.62.0（88）已成功安装到 iPhone 17**。本轮扩展已发布四角色共用的宿主交互与真实 AI 链路，不修改原始角色资产。保留右上角位置编辑器的独立、持久化控制。

## 交互与兼容决策

- 未打开位置编辑器时，单指临时旋转保持原规则；双指仅控制临时缩放，不读取双指中心平移或扭转。撤去一指即结束，余指继续滑动不新开一次单指旋转。
- 相对用户已保存视图，缩放限制 0.90–1.10；放大还检查设备构图边界。不会为了容纳缩放而平移角色、改变保存位置或挪动相机。释放后阻尼恢复至 1；进入编辑、切页与输入取消均结束临时手势。
- 原生同一识别器负责单／双指切换，桥接使用递增 `previewToken`；Unity 的临时比例与持久 `CharacterViewPose` 分离。运行时修订为 12，导出检查同步拒绝不支持轻捏的旧版本，避免新版界面搭配旧 Unity 包。
- AI 请求新增 `model_pinched`，`pinch_out` 表示拉开放大／轻扯拉近，`pinch_in` 表示收拢缩小／轻捏。既有 `model_shaken` 仍只表示旋转晃动。字段是增量扩展，不改旧存档。
- 目标比例变化至少 0.055、持续至少 0.22 秒时即可在松手前取得反应资格。旋转／两种缩放共用 20 秒冷却，后端按账号与角色再防重。正在播放或生成时最多等 15 秒，不抢掉当前话轮。
- 撒娇／轻微生气、短台词与多组表情动作由现有真实 AI 流程生成，按朗读音量播放。提示词明确区分三类互动；缩放草稿若误称摇晃、转圈、头晕，在原有有界预算内重写，发布前拦住，不朗读错误草稿。没有新增固定投诉台词或重新创建音色。

标准接口见 [AI 表现标准](../../character-standard/08-ai-performance-standard.md)。

## 测试故障的处理与证据边界

初版定制多指注入将第二个触点设为非零起始时刻。Xcode 26.4 在该路径注入了额外的结束／重新开始事件，导致识别器只收到起止、没有有效连续缩放。通过限定的 UIKit 事件记录定位后，使用 XCTest 标准 `pinch` 验证真实连续触控；需要同时验证双指中心移动的用例改为两指同时落下，保留错开抬指和余指移动。这些测试不绕过 UIKit 直接调用 Unity 桥接，也没有放宽比例和存档断言。

一次尝试切换到私有 RunnerDaemon 的诊断路径导致测试运行器退出，已完整撤回。此前失败日志保留，不作为通过证据。实际 UIKit 下“单指已转动时再加入第二指”的错时注入，本轮未形成可靠的自动化证据；不把同步双指成功等同于这项已验证。应用中的切换逻辑及 Unity 取消／接续仍保留，后续可用稳定触控注入或真机人工补验。
