## 资源与播放

- 24个不同乐谱事件序列、24份不同PCM、24个不同CAF资源。变化包括旋律、和声走向、音色、调式、速度和节奏；没有通过改标题重复使用原来的两首录音。
- 单曲20–29.09秒，8小节循环。基于正弦及受控泛音合成柔和钢琴、钟音、拨弦、木琴和低柔电子音色，保留足够的对话空间。
- 声部释放尾音和混响使用环形叠加，尾部自然回到开头，不在每次循环制造静音。播放器保留0.45秒渐入、同角色换曲交叉淡出，以及说话时降到18%背景音量、录音时暂停、离开/锁屏暂停的既有行为。换角色立即停止旧角色音轨。
- 使用系统 afconvert 编为CAF/Apple Lossless；24首总计19,022,929字节，以最终 audit 的 totalBundledBytes 为准。没有AAC编码延迟或有损接缝，已逐首解码回16-bit PCM比对全部样本一致。仅在作者工具里需要现有NumPy，App内由AVAudioPlayer播放。

## 角色隔离与旧数据

`CharacterCollection`保持schemaVersion 1，新增可选 `scopeID`；曲目新增可选 `assetExtension/sourceModelID/sha256/duration`。

`scoped(to:)`保留角色快照的动作、环境和声音定义，从相同底层`modelID`的当前资源库取得专属音乐，并将voice/music/default IDs重映射到该角色实例自己的前缀。自建角色共享其基础角色的物理只读文件，但拥有独立逻辑ID和选择记录；`sourceModelID`始终表示底层模型，不冒充自建实例。

旧的base前缀偏好按原suffix迁移；其他角色和同base兄弟实例的选项不会被接受。旧快照里的IslandAfternoon/MoonlitTide会在进入scoped集合时升级为该base的两首专属曲目，而冻结的环境/动作集合不被替换。两份历史WAV暂留作旧schema快照兼容，新的内置集合不再引用它们。

## 验证与证据

- `audio-audit.json`：24首CAF逐字节无损回译、文件/PCM/乐谱三种独立SHA-256、声学边界和时长。
- 全曲峰值最大约0.3874（约−8.24dBFS），RMS约0.075（约−22.50dBFS），最大直流偏置小于2.2×10⁻⁸；最大循环接缝差为一个16-bit采样量化单位（1/32768），最大接缝斜率差约0.001465。这里是资源信号检查，不把它声称为真机听感或声压测量。
- `integrity-tests.log`：原20首接入时的4项实际文件验证通过，覆盖合法集合、伪装他人音源、重复使用同一录音、篡改实际音频字节；新增角色需在最新模型目录生成后再跑同一组测试。
- `check_character_collections.py`在构建前校验角色归属、ID前缀、文件名、真实文件SHA-256及对应作者检查记录，拒绝串角色和旧两曲占位回退。
- 改动Swift语法检查通过；`CharacterCollection`真实生产代码配合最小依赖stub的Swift语义编译通过。本机独立执行测试被AMFI拒绝adhoc/未知证书签名，main未执行，未计入运行通过；完整实例迁移、播放器和界面验证由正常App构建流程完成。

重新生成全部曲目：`.local/character-venv/bin/python scripts/generate_soundscapes.py`。增量生成指定角色：同命令加`--only anime-kipfel anime-mamehinata`，此入口已实际执行，只生成4首新音频、保留其他角色的资源与审计。仅修复重新生成角色包时的音乐目录：同命令加`--catalog-only`，可同时传`--only`；该操作只同步选中角色的音乐/集合版本，不改动作、环境或声音。

2026-09-29增量验收：对旧20个CAF逐文件比对SHA-256，旧10个集合对象及旧20个审计条目逐值比对，全部不变；新增4首文件/PCM/score独立性、ALAC无损解码、接缝/电平边界通过。新角色默认背景分别为garden / sunroom，natural与soft语速分别为0.96 / 0.90；每个角色只绑定自己的两首曲目。完整运行时目录验证与新角色实际播放由后续统一Unity/App接入验收承担，不以本次音频资源验证代替。
