# 星夜 0.26.0 / build 39：角色资料与原生手势

本轮已完成代码、iPhone 17模拟器回归、Device Release签名构建、手机无线升级与启动。最后正常启动没有传入测试参数，保留原Bundle ID及用户资料。回读手机版本0.26.0 / 39，启动后确认应用进程存在；[安装记录](device-installation.json)。真机触摸自动化未执行成功，不能将安装成功或模拟器手势通过解释成真机触摸已通过。

## 交付清单

- 对话页删除名字下方副标题，32pt圆头像在名字左侧；点击共同打开角色资料。
- 角色头像统一圆形：发现、消息、关注/创建列表、创建角色选项、旧角色卡组件；账号头像同样圆形。外观缓存仍与保存的角色配置匹配。
- 发现双列卡片约102pt高，38pt圆头像，名字、性格、两行邀请。删除卡片关注状态与聊天按钮，整卡先看资料。
- 资料包含头像、名字、性格、简介、关注、进入会话、定制。发现资料为实底；会话资料背后保留3D的渐变。定制及其子页保留原有验证/保存/预览，返回定制→资料→会话，点击外部关闭整个弹层。
- 首页/消息/发现/我的只显示14pt文字，垂直居中对齐中间加号，底栏尺寸未变。
- 只有实际播放语音时顶部头像显示两圈扩散波纹；停止后移除，减弱动态使用静态环。
- 模型手势改为原生UIKit识别器→归一化桥接→Unity命中/取景。默认仍锁定旋转缩放，点头不受锁定影响。原生手势开启后引擎旧触摸轮询关闭，防止重复动作。两个Unity导出均包含nativeGestureRevision 1并通过构建检查。

## 验证

`Starry-Identity-Native.xcresult`：4条核心用例通过，119.176秒用例执行时间（不含构建和runner启动）：

1. 原生触摸面收到实际屏幕事件：头部计数0→1；锁内拖动不改取景；解锁后拖动至-20°、捏合至110%，持久化手势计数0→2；消息页返回同一角色，再次点头计数1→2。
2. 顶部资料→定制→资料→会话；发现卡片→资料（没有加载Unity）→会话；发现资料还能定制驻留角色。
3. 实际合成/播放语音后头像有波纹，点停止后无波纹。截图及运行时avatarVoicePlaying由true转false；未播放的消息语音控件保持静态。
4. 消息页在初音未来/Luma间切换、重复恢复同一角色、继续输入文字并点头。没有重建同角色会话，首个可见状态相机已稳定。

截图复核发现发现页透明资料与底层卡片文字重叠，改为实底后只补跑受影响的资料导航：`Starry-Identity-FinalSurface.xcresult` 1条通过，30.460秒。本目录资料页截图已替换为最终实底版本。

初次UI流程失败是测试截图辅助代码错误读取发现页不存在的3D探针，已改为仅探针存在时读取；并非资料页运行崩溃。历史结果保留于.local/checks。

手机自动化尝试在测试启动前退出，错误为XCTest连接通道被拒绝、IDE断连、runner exit74，两次均未开始触摸用例。手机报告iOS27.0，当前Xcode SDK26.4；记录这些事实，不把版本差异未经证明地当成唯一根因。实际手机安装、版本回读、启动及进程检查均成功；测试runner临时App已清理。仍需用户实际点按确认本版在手机上的最终手势效果。

用户最新约定：今后以模拟器持续开发，真机安装只尝试一次；连接或安装失败即转模拟器，不等待手机、不反复重试、不耽误后续开发。本轮收到约定后的正式安装一次成功。未新增iPad测试，也不使用模拟器结果承诺真机帧率。
