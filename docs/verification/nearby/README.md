# 近伴 0.19.0 / build 32 结果与验证

2026-09-28。只验收 iPhone；未安排 iPad 测试。手机 Release 已编译并通过严格验签，22:42 最终版本无线更新安装完成；设备版本及启动结果见 [脱敏安装证据](device-installation.json)。应用稳定标识保持不变，未卸载、未清空个人记录。

## 交付清单

- 四个基础角色各有独立集合声明：模型、按钮动作、允许的背景、说话节奏预设和音乐；创建实例保存集合快照。存储、预览和保存按账号/实例/集合范围隔离，换角色停止旧音乐。
- 初音提供静夜小屋/柔光影棚；Luma 提供柔光影棚/清风小院；小夏提供晴日客厅/林间花园/海边露台；小乐提供清风小院/林间花园。空间允许共享只读底层文件，各自布置独立。
- 每个角色两种声音节奏预设、两项独立曲目绑定。当前复用一个离线中文音色和两个原创音乐文件，不声称拥有多个训练音色或八首新音乐。
- AI 回复默认完整分段朗读；新使用者不会继承发布者个人的静音/音乐开关；聊天栏喇叭立即停止/恢复后续自动朗读，当前角色记住静音选择；音乐启停、曲目和音量分别保存。
- 首次游客进入初音对话，消息可用。接受一条用户消息时原子预留一轮，最多五轮；第六次发送要求登录，中断或清历史不重置额度。第五轮的声音不被强制登录弹层打断。
- 新账号默认关注初始角色并承接游客记录一次；已有账号恢复最近关注角色，已取消全部关注时首页与消息都显示发现/创建引导，不再以旧历史填回关注。
- 发现缩为紧凑双列卡片，固定搜索/筛选；本地搜索覆盖名字、原名、性格、语气、故事，多词匹配、忽略大小写/全半角并支持清空及无结果提示。
- 我的改为用户头像、账号、签名、实际关注/角色/聊过数量，关注/作品切换；设置收纳登录账号、主题、关于与本机身份切换。
- 默认深海蓝；暖夜、松林、月白备选，轻透/沉静样式。重启保留，SwiftUI 与 UIKit 均更新；界面主题不改角色外观和空间。
- 名称、图标、登录/关于/资源说明统一为近伴；品牌原图和完整生成提示词留档。名称未进行商标注册审查。

## 实际验证

| 验证 | 最终结果 |
| --- | --- |
| `bash scripts/test_character_library.sh` | 41 项通过：集合合法性、越界背景/声音/音乐归一、同底座实例与账号隔离、游客额度/中断预留/清历史/重启/承接、旧档兼容、公开隐私和目录未来版本保护 |
| 集合编译门禁 + JSON Schema | 4 个集合、16 个命名空间内音频选项通过；集合模型/动作/场景/资源引用合法 |
| iPhone 17 UI：集合/音乐/背景/静音隔离 | 50.709 秒通过；实际 AVAudioPlayer 在播放，角色切换后选项不同、默认音乐关闭，回到初音恢复 15% 音量和原曲目 |
| iPhone 17 UI：游客五轮/离线声音/登录/空关注 | 最终 58.683 秒通过；语音计量 `audioSegments > 0`，重启额度不变，第六次进入登录，5 条回复迁入新账号，取消全部关注后首页/消息为空，重启仍为空 |
| iPhone 17 UI：紧凑发现/搜索/个人页/主题 | 最终 24.759 秒通过；四项同屏可点击，卡片高度 < 210pt，搜索过滤与无结果，切换松林/沉静后重启保持 |
| 原生宿主 Simulator / Device Release | 构建通过；签名 `codesign --verify --deep --strict` 通过 |
| 本轮原生/脚本/文档 diff 检查 | 通过。仓库历史 Unity 生成资产保留既有行尾空格，未改动本轮范围外的生成文件 |

最终 UI 结果保存在 `.local/checks/Nearby-Phone-v019c.xcresult`、`.local/checks/Nearby-Guest-Final.xcresult` 和 `.local/checks/Nearby-Theme-Final.xcresult`。模拟器使用独立的 iPhone 17 QA 设备，未操作其他项目的模拟器。没有声称全量历史 UI 用例已迁移或本轮测得持续 120 FPS。

初始失败已保留：首次卡片容器覆盖子按钮标识，增加独立无障碍容器后解决；音乐检查曾用 JSON 文本直接匹配含斜线 ID，改为先解析 JSON；发送辅助函数曾把上一条回复误当本次完成，改为等待回复数量增加，再验证五轮。图像采集另等待界面淡入完成，避免将过渡帧当最终页面。用户对话逻辑没有为通过测试注入额外额度或跳过登录。
