## 测试修正与范围

最初 UI 测试错误寻找真人首页的独立舞台按钮，实际入口是角色图片；修正为真实入口。第二轮在动作后等待 XCTest 谓词，工具约一秒的轮询已经错过过渡，误把收稳状态当成失败。最终将三个按钮紧邻点击，用 UI 验证最终状态、用 Unity 原始事件验证瞬时连续性，避免为了适配测试工具而放慢动画。

Phone-1 包含失败的初版动作测试及通过的手势回归；Phone-3 是最终动作测试。iPad-1 两项均通过。失败原始记录保留，未当作成功覆盖。

使用独立 QA 模拟器避免用户同时操作造成干扰；普通 iPhone17 模拟器也已更新并打开小夏聊天。独立 QA 设备关闭，workspace 保持 device 配置。手机离线语音和原有资料继续保留。
