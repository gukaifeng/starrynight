2026-09-28。新增微信、邮箱、手机号三个登录入口，共用固定账号“小伴体验者” `XB-000001`。本次仅提供真实可操作的本地演示，不接真实鉴权、验证码或云端同步。

## 使用方式

更新后首次打开显示登录页，默认微信，点“微信一键登录”即可。也可以直接切换邮箱／手机号，预填信息和验证码均可直接登录：

| 方式 | 默认内容 | 操作 |
| --- | --- | --- |
| 微信 | 小伴体验者测试身份 | 点击登录，不拉起微信 |
| 邮箱 | hello@xiaoban.example / 123456 | 点击登录 |
| 手机号 | +86 13800000000 / 123456 | 点击登录 |

“获取验证码”会回填本地演示码，明确提示没有发送短信或邮件。登录状态在重启后保留；首页右上角头像按钮打开“我的账号”，可查看三个测试关联入口并退出。退出不会删除既有角色、记忆或聊天记录。
