# 账户页面布局 · v0.26.3 / build 42

“我的 → 顶部身份信息”打开的页面已统一命名为“账户”，独立账户入口与辅助功能提示也同步更新。

页面采用原生 insetGrouped 列表，保留月白及其他深色主题。圆形头像与“我的”共用同一组件；头像和身份置顶，下方依次为账户信息、登录方式、退出登录。条目标题与对应内容左右对齐，分组使用轻分隔线和次级标题。登录方式目前只展示测试绑定信息，不增加没有实现的解绑、修改或安全设置入口。

本轮只调整页面展示，AccountStore、三种测试登录共用身份、退出保留本机资料的逻辑均未修改。返回继续使用现有弹层关闭机制。
