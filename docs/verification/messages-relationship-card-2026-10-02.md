# 消息页：相处资料与会话管理

消息列表仍保留左滑后的“不显示”和“删除”，但普通点击先展示该角色的相处资料卡，不再立即进入会话。资料卡从当前账户的本地记录读取聊过的句数、用户发言数、记忆条数、最近一句和初见日期；“羁绊”仅按真实消息量显示粗略阶段，不把它伪装成服务端关系评分。首层可进入会话或隐藏列表条目；重置入口在同一弹窗的“更多”子页面，随后沿用原有二次确认与服务端删除流程，警告会清空对话、记忆和相处进度。

滑动条目的内容与右侧操作区之间加入随展开进度渐显的暗色过渡，保留原本的横向手势识别和纵向列表滚动路径。新增 UI 用例检查点击资料卡、次级重置入口与返回路径。iOS 真机 Release 源码编译已通过；新 UI 用例仍需模拟器执行，不能据编译结果推断交互画面已验收。
