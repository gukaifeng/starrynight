# 聊天显示偏好、可读历史与统一返回 · 小伴 0.13.0 / build 23

## 使用方式

聊天页右下「… → 我们的空间 → 聊天显示」，设置高度 35%～70%、字号 14～24；默认半屏 / 16。返回或点窗外后自动保存，所有角色共用，可恢复默认。竖屏按屏高，横屏按右侧可用高度映射，受安全区和键盘约束；字号作用于消息、流式回复、输入与历史正文，主要聊天正文还跟随系统文字缩放。

向旧消息方向继续拖动，可以把第一条消息的开头移到清晰区。列表顶部保留实际可滚动留白，长度取自渐隐遮罩完全显现的位置加 12pt；随高度、键盘变化重新计算。不是临时弹性越界，也没有关闭渐变。空会话不添加此留白，系统降低透明度时不需额外留白。列表仍保留最近 60 条窗口；更早记录在「聊天与资料」中查看。

## 关闭契约

所有应用自有弹窗都有左上返回，移除用于退出窗口的「完成／保存」按钮；点击窗外（含被遮在下层的页面返回位置）关闭当前窗口，不离开角色页。下拉/侧滑也走同一关闭请求。取景、定制、角色资料、聊天显示在退出前提交，写入失败显示错误且保持窗口；音乐实时保存。记忆的「保存记忆」是明确添加记忆的业务动作，继续保留；系统分享、选择器和删除确认仍遵循系统行为。

`SoftPanelCloseRequest` 协调退出前校验和关闭锁，`SoftSheetPresentation` 在面板后放置透明点击区域，消费点击，避免同时旋转模型。UIKit 取景/定制和 SwiftUI 音乐/资料/历史/账号/关于共用同一条路径。保留已有弹簧位移和淡出，不重建 Unity、切换摄像机或增加截图材质。

## 设计与兼容

沿用 frontend-design 技能及既有「角色主体、安静工具」方向：暖白 #F7F5F0、浅玉 #B8D5C5、深绿 #274A43、次要字 #5B7168、卡片 #EAF2ED；标题系统 Medium、消息用户自选正文、数值等宽。设置页只有两个滑杆和真实字号预览，返回与点击外部退出；不增加独立聊天风格或下载素材。

偏好是 CompanionArchive 的可选 `chatDisplay`，schemaVersion 仍为 1，旧文件缺省使用原值，恢复过程保留角色、记忆和消息。滑杆预览走内存，退出时原子写入一次；有损坏文件保护时不覆盖。所有值在加载和布局前限定范围并拒绝非有限数值。

技术依据：[Apple UIPresentationController 自定义视图生命周期](https://developer.apple.com/documentation/uikit/uipresentationcontroller)、[Apple presentationTransitionWillBegin](https://developer.apple.com/documentation/uikit/uipresentationcontroller/presentationtransitionwillbegin())。具体保存/返回语义及留白长度为本项目产品决策。

## 验证归属

最终结果以 results.json 为准。自动化专项覆盖高度/字号两端、首条消息进入清晰区、重启恢复、恢复默认、横屏大字键盘、返回和窗外关闭、取景/脸型/昵称保存、音乐滑动退出、账号和关于。实际截图随结果归档。

原有 UI 用例已更新返回按钮及保存语义；未将未执行的整个历史套件声称通过。核心数据检查复用实际生产 Codable / persistence，在独立 Swift 解释器中只将 Bundle 资源定位替换为仓库同一目录文件。首次解释器缺少 app Bundle，触发目录前置检查，修正测试入口后通过；生产 Bundle 逻辑未改。

早期 Phone-1 的显示/历史用例通过，但窗口用例用了错误的 faceWidth 自动化 ID 而失败；修正为 studio-faceWidth 后 Phone-2 两项通过。最终再增加滑动退出、脸型回读和大字号横屏键盘覆盖。早期通过项不代替最终整体结果。

补充验证处理：一次 iPhone 触摸合成在启动另一模拟器期间超时，保留日志，不认定应用或模拟器某一方为已证实根因；后续逐设备运行。iPad 滑杆手势实际选择 36%，先前测试写死 35% 导致误判，改为比较实际选择与重启回读值。手机横屏测试的通用 firstMatch 滚动选区触到窗外而关闭面板，依据原速测试录像修正为在可见侧栏内拖动，并为设置列表补充明确标识；没有移除窗外关闭功能来让测试通过。

## 最终结果

iPhone 窗口专项 91.666 秒、显示与首条阅读 64.854 秒；iPad 对应 92.654 / 65.176 秒，采用四项通过方法，精确包归属见 [results.json](results.json)。382 条窗口/键盘/高度几何断言通过，核心数据兼容通过。最终截图检查第一条内容清晰、大字号输入与发送/收键盘可见。
