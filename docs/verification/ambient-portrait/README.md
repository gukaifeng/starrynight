# 0.61 会话活动、取景与表情语义

星夜 **0.61.0（87）已于 2026-09-30 安装并启动于 iPhone 17**，CoreDevice 安装及启动均返回成功，启动 PID 24723。本轮针对已发布四角色共享路径，未修改用户提供的源模型；未新增 iPad 测试。

## 实现与决策

- 删除两份 GitHub Actions workflow，继续普通提交和推送；本地测试和资源恢复文档保留。
- 待机根转动间歇随机，包含左右与俯仰；讲话目标幅度约减半。固定身体中轴，阻尼衔接，编辑/手指拖转时让位；不修改原作骨骼或账号保存的视图。
- 晃动投诉的资格判断移入运行帧，阈值达到即触发，不再依赖松手；取消无意义的前置 350ms 等待。已有语音轮次未结束时仍顺序排队，AI 服务响应和合成耗时不等于手势资格延迟。
- 根据每个模型中性眼骨、头骨、总高和顶部轮廓生成取景数据。优先保持脸部屏幕锚点，再解算安全距离；中性数据缓存，不随自动转动与打开面板重新测量。
- 卡琳、戚风的原作手势会同时驱动脸。新 `ai.kind` 明确语义，调度器从真实目录匹配分组，不再硬编码 `expression` 菜单名；恢复共享枚举参数时只重放原选中项。

## 问题与处理

第一版取景先装入整个包围框，导致长耳卡琳的脸下移至画面高度约 44%；改为固定脸部目标位置、退后留出耳朵空间。最终四角色在四种手机窗口的脸部标记均位于约 62%，不能把总高一致误当作面部位置一致。

编译时曾发生新取景生成器与已有头像生成器重名，已恢复原头像工具并将新类独立为 `CharacterPortraitCalibrationBuilder`。失败日志保留；后续完整检查重新执行。
