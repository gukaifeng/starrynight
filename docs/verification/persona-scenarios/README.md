## 问题与处理

1. **新 App 的角色简介被旧服务覆盖。** 首轮模拟器在资料内容断言失败。补充公开人设版本，旧远端版本不能覆盖更新的内置版本；部署服务后复测两项通过。
2. **中文心声校验会丢弃英文。** 原先只接受含“我/咱”的短句。服务端、iOS 同时增加英语第一人称规则；继续隐藏模型的回复计划，心声不进入朗读。
3. **中文静态素材旁白混进英语会话。** 英语模式保留真实动画与英文心声，省略未翻译的原素材文字，避免额外翻译调用拖慢首句。
4. **旧故事只发送开场提示。** 现在每次对话、待机和缓存准备都有角色所属的场景 ID；暂停显式回到日常，再次进入使用续聊意图。原有故事 ID 保持兼容。
5. **剧情智能回复无法命中。** 原校验只接受 `user_message`。新增 `story`，预生成分支也用正确触发类型；正常聊天和剧情各有测试覆盖。
6. **macOS 命令行 Swift 测试被 signal 9 终止。** 不把它记录为通过；改用 App 中的同一核心契约测试，在 iPhone 17 模拟器内验证通过。
7. **测试脚本使用已移除的 audioop。** 当前 AI venv 是 Python 3.14；改用已有 FFmpeg 做 PCM 采样率转换。新增 `--resume-asr`，复用已付费生成的音频，不重跑四次对话及两次朗读。
8. **少量样本的内容不足以保证长期剧情质量。** 实测真冬开头过于反问、英语建议会猜测用户职业；加强表达自己立场和不编造用户背景的源头约束。后续短复测保留在本机，仍需实际多轮体验，不能把结构通过等同于每句话都精彩。

可复现的付费小样本入口：`scripts/live_persona_scenarios_smoke.py --allow-paid`；常规测试不运行它。完整原始响应、音频、使用记录与设备回执留在 `.local/checks/persona-scenarios/`。本轮未做真机 GPU、120 Hz、耗电或任意服装碰撞性能测试。
