# 聊天内容与气泡渐隐 · 0.12.1 / build 22

用户希望内部内容比聊天区域背景更早变透明，减轻半屏聊天与人物之间的割裂感。

## 设计与实现

- 保留原暖白/玉绿颜色、系统圆体和全屏角色。区域背景继续使用原 smoothstep 长渐变；消息内容采用独立的平方 smoothstep，向人物一侧靠近时更快淡出。
- 在整个消息 ScrollView 完成文字、气泡背景、流式回复、消息操作绘制后，统一施加 alpha 遮罩。遮罩固定在可视区，不随某条消息移动；长气泡滚动经过边界时逐段消失，不是整条消息一起骤变透明。
- 去掉原顶部最多 80pt 的限制。正常消息区中，渐变覆盖约 82% 高度，最上方还有一段完全透明区；下部预留至少 64pt 的阅读空间，末端另有不超过 16pt 的柔和收边。键盘让窗口很短时缩短渐变，防止把全部内容淡没。滚动旧气泡到固定工具栏前也会淡出，列表底部留白保护最新消息操作，不再出现笔直的裁切线。
- 状态、音乐和工具入口移至消息下方、输入框附近，避免中间边界留下一排不透明胶囊。推荐话题仅用于空会话，开始对话后为消息让出空间；空会话邀请文案放在消息区下部，仍然可读。
- 输入、发送、收键盘、返回最新等主要控件保持可见，滚动指示条继续隐藏。系统“降低透明度”开启时消息遮罩为不透明，优先阅读。
- 原生 SwiftUI 改动，复用已校验的 framingProtocol 7 Unity 导出；没有改变相机、模型制作接口或下载运行依赖。
