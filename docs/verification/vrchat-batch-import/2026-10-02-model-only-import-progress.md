## 已实现的变化

- 眨眼按启用的眼睑类型读取 Descriptor；未启用配置时不使用残留的零索引。选中的形变必须具有有限且非零的顶点位移，排除 viseme 和张嘴绑定；支持同一脸部网格的左右眼组合，不再因层名含 Blink 就判定原作已经自动眨眼。
- 预览封包不再主动清空衣发骨段及碰撞体；本轮候选重新从精确源路径恢复物理数据，保留原始物理系数和适配限制。
- 物理解析跨全部经过审计的依赖包按 GUID 合并。雫的基础 Prefab 位于另一个 unitypackage，现找到 12 条启用的物理链，候选中映射为 149 个宿主骨段。
- 重复生成端点按实际向量区分，重建保留稳定节点；角色的原始骨骼、网格及 ZIP 不重命名、不修改。
- 新增 secondary-motion@3 的局部碰撞半径语义；旧 1/2 包保持旧单位。SDK 和 Unity 按碰撞骨完整缩放求有效半径，修复真纪、Shiratsume 等模型因小碰撞骨缩放而被错误拒收的问题。
- 预览由角色集合的 previewOnly 决定。删除将所有模型静音、禁止请求和禁止账号同步的全局开关；完整角色保留正常对话、语音音量和账号同步。已接入 AI 的完整角色仍可构造正常请求，预览角色的请求在账号路由前被拒绝。启动清理错误安装曾写入的全局预览偏好。
- 生成和激活脚本只处理已声明 previewOnly 的角色；显式选择完整对话角色做预览转换会被拒绝，避免未来再次覆盖。完整包的 manifest、speech、原 AI 表现字段及资源从私有备份整体恢复，而非仅恢复 UI 按钮。 对 11 个完整包的 332 个文件逐一核对 SHA-256，文件名集合和文件内容均与改动前备份一致；11 份集合配置也完全一致。显式尝试将琪宝转换为预览已被拒绝，未写入角色候选。
- Unity 隔离审查读取明确候选路径，避免旧 visual 目录覆盖本轮候选；物理 240 帧采样、角色转动响应及 801 个现有控制复位检查已真正运行。逐角色自动眨眼另检查实际运行时，兼顾原作动画自行控制眼睑的来源。
- 新增整批激活脚本：先校验全部角色的 manifest、动作数值回执、控制覆盖和图片哈希，再保留旧包与集合版本并替换活动包；失败回滚。本轮旧包保留在 private 激活目录，不修改用户源 ZIP。

## 后续执行入口

本轮保留完整角色正常对话，先安装其余角色的模型预览，便于用户查看真实模型。缺失原作控制、动作、粒子和约束继续明确记录，不能因预览安装而关闭完整效果工作。11 个没有有效原作身体待机的来源仍按宿主适配处理，不能把原静态站姿称为完整呼吸动画。

```bash
# 仅生成基础模型候选，遇到未适配原作效果仍记录为 incomplete
.local/character-venv/bin/python scripts/prepare_character_model_review.py

# 明确读取上述候选；生成新画面/物理回执，不会更新发布名册
unity run "$PWD/unity/CharacterRuntime" --timeout 900 -- \
  -executeMethod PortableAvatarReview.RunModelReview \
  -logFile "$PWD/.local/logs/character-model-review.log"

# 预览激活前执行整批预检；--apply 会保留旧包并替换
.local/character-sdk-venv/bin/python scripts/activate_character_model_review.py

# 真正重新 Setup/Validate/Thumbnail，导出并安装预览
python3 scripts/export_unity_ios.py --platform device
bash scripts/run_device.sh DEVICE_UDID --shell-discover
```

仅运行当前候选的 Unity 审查不会自动补齐表中的缺口。发布替换必须与角色目录、集合版本及真正的 Unity 导出一起完成；不得复用旧 manifest 的画面回执，也不得只改 catalog stamp 来表示新模型已导出。
