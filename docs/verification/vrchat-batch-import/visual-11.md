# 第十一批：Ririka、Rurune、Shiratsume、小春

四位角色均封包并经 Unity 隔离渲染后加入本地名册，保留角色独立 ID 和来源封面。原作控制未开放，AI 图片/语音/音乐接口未调用。Ririka 因单包超过 256 MiB 约 1.5 MiB，只在预览副本里将一张 4096 法线贴图缩至 3072；源纹理未改。默认未显示的网格被排除，保证 300k 顶点预算内的当前可见造型。

Rurune 的原作 Idle 在便携坐标中把人物移到地面以下。预览包改用隔离检查时记录的宿主站立姿态，并在回执中标明适配；重渲染后完整人物可见。这不等于原作 Idle 或其他动作已经迁移。Shiratsume 的原作碰撞器超出当前安全范围，本预览不运行这些碰撞器。四位的最终渲染图和 manifest 哈希绑定检查保存在私有 `.local/vrchat-batch/render/`。

整库名册 41 个角色：来源目录中 39 个具备完整本体的角色均已纳入，另有此前独立来源的豆日向，以及独立保留的新旧小猫两版；龙胆仅服装包，继续跳过。

整库 Unity iOS simulator/device 导出和 41 角色集合校验通过。iPhone 17 模拟器 UI 用例实际打开真央、Ramune、露露奈、小春四个末批外观预览，均未显示 AI 输入框；另有第七批四个角色的专项打开测试。真机 Release 构建第一次因磁盘空间不足在复制资源包时失败，清理可重建的 Unity `Library/PlayerDataCache` 和 `Library/Artifacts` 后增量重试通过；完整 App 约 14 GB，已用 `devicectl` 安装并启动到 iPhone 17。命令成功不代表 41 个角色逐一经过手机目视检查，也没有完成真机帧率采样。原作动作和依赖适配仍是独立验收项。
