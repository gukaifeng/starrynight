## 通用修复和边界

1. 解析 Material Variant 的父属性与显式清空，解决小虎全白；带权骨索引重映射，解决大量未用骨骼触发预算；nested Prefab 的 source GUID/fileID 定位，解决草莓 PhysBone 链丢失。
2. 按本地静止桌面会话专门化源控制图；菜单、曲线、driver 可写参数保持动态。消除确定不可能发生的 locomotion 分支，绝不因缺失资源而消除可达动作。
3. 统一 AI 语义、public profile 和 worker 人设 JSON 部署；后端使用追加迁移，保留旧账户/对话/订阅。
4. BuildIos 原来假设角色必须高于 1 米，误拒绝原作小比例角色。校验改为有限且合理尺寸，实际会话取景仍由每位角色中性头眼位置测量。
5. Unity 在完整 Setup/Validate/缩略图成功后于 URP 构建回调崩溃。保存失败日志，新进程 ExportPreparedSimulator 成功，不绕过 Validate。
6. 两次 UI 失败是测试器读取发现页不存在的会话探针，以及横向大幅滑动越过窄分组；分别改为条件采集和小幅定向拖动，重新跑完，未删除失败记录。

物理仍是有界弹簧适配，不等价 VRChat。Ichigo 的 Ground_Col 和 Nozomi 的体型关联 PhysBone 开关属于来源 MonoBehaviour 动态参数，当前通用曲线执行器未迁移这些参数；它们的存在已记入限制，不以可见表情测试掩盖。源 Contact、世界约束、所有自定义 shader 和多人功能不自动算已支持。

验证区分：源解析/封包、Unity 控制采样、模拟器 UI、真实 AI 返回、设备安装分别成立；尚无完整会话真机 60/120 FPS 的证据。
