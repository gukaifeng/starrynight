实际发现并处理：

- 旧场景没有统一颜色分组，影棚也没有独立 accent Renderer。构建器只为存在的组声明绑定，不制造空绑定绕过校验。
- 花园的石质地台最初被归入可选装饰，地面保护检查阻止了构建。改为永久结构，装饰开关不能隐藏站立地面。
- macOS 的临时目录路径经 `/var` 符号链接进入 `/private/var`，首次资源封印测试被安全检查拒绝。先解析调用者提供的根目录，再对包内路径检查穿越/软链接，保留安全限制。

- 第一轮 UI 流程发现卡片与全部调节项放在同一长列表不够方便，分为同一弹层内的“选择空间 / 布置与光影”，保留实时预览、过渡与无滚动条设计。
- 逐图复查发现花朵/坐垫的配色组与装饰组分离，隐藏植物/长椅后可能残留悬空部件。将配色子组归入装饰层次，同时树木与栏杆作为空间主体保留。

- iPad 横竖屏自动化曾在旋转过程中读取到旧按钮坐标。测试改为等待实际 Unity 画面比例和原生按钮位置就绪，不延长固定休眠。另将“恢复推荐 / 重置当前空间”固定在面板底部，避免滑杆区域拦截滚动时找不到重置；人物恢复推荐只重置人物，不删除空间设置。

房间与室外场景当前为程序化基础美术，小院为最小独立 GLB 示例；不声称摄影级环境、天气模拟、实时波浪、任意家具编辑或持续真机 120 FPS 已验收。
