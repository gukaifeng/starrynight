# 星夜 0.20.0 / build 33 — iPhone 沉浸对话验收

最终名称保持 **星夜**，新图标为黑底彩色星与光轨。方案见 [设计和关键决策](../../design/2026-09-28-starry-immersion.md)。

## 需求结果清单

| 用户要求 | 实现结果 |
|---|---|
| 顶部返回/定制更透明 | 14% 背景不透明度、细描边、44 pt 点击范围；系统降低透明度时尊重无障碍设置 |
| 删掉角色名字后方大黑色渐变 | 删除 topScrim 层，仅文字局部阴影保留可读性 |
| 取消头像加载页面、快加载不闪烁 | 没有头像加载页和最短等待时长；来源页面保持至实时窗口渐入完成 |
| 智能预加载，采用成熟算法 | 一阶 Markov 访问转移预测，频率/对话历史回退；按账号保存，空闲时离屏准备一名候选的资源 |
| 删除每条消息长按菜单 | 复制/记住/喜欢/重新回答/简短回复的长按入口和对应专用会话方法已删除 |
| AI 气泡左上角播放与时长动效 | 彩色环形播放/停止、真实音量驱动音柱、当前时间；首次估时明确“约”，完整音频后保存实测时长 |
| 黑底彩色渐变默认主题 | 星夜为新默认，青绿/淡蓝/暖粉/淡金局部渐变；保留其他主题和已主动选择的偏好 |
| 人物更突出 | 对话腰部以上近景、眼睛位于屏幕约上四分之一；全身动作仍平滑拉远再恢复 |
| 我的顶部身份合并登录 | 点击身份打开账号与登录；游客点击身份打开登录 |
| 我的关注/创建角色收进列表 | 两个独立入口，分别打开列表页 |
| 消息行及头像缩小 | 42 pt 头像、上下 11 pt 间距；实测默认行高低于 80 pt |
| 初始角色集成、首开快速可见 | 初音与资产随包，场景直接默认激活；匹配默认设定时立即显示真实模型预渲染全屏场景，再由实时 3D 渐入接管 |
| 跨菜单不重新加载相同首页 | 保留角色、会话、HostingController、输入草稿及取景；仅暂停渲染/声音，回来不 selectModel 或重置摄像机 |

## 实际检查

- `CharacterLibraryTests`：41 项集合范围、角色/账号隔离、游客五轮、搜索、公开权限、迁移、持久化检查通过。
- `CharacterPredictionTests`：8 项 Markov 后继/频率/对话回退、当前角色排除、候选权限过滤、持久化、过期、容量检查通过。
- `Starry-Immersion-Final-v020.xcresult`：iPhone 17 模拟器 5 条流程，221.249 秒，0 失败。分别为原场景/音乐/静音隔离 53.535 秒、游客五轮/离线声音/登录继承/空关注 58.129 秒、气泡真实语音/时长/重启恢复/无长按菜单 26.714 秒、冷启动取消/角色切换 23.499 秒、跨菜单不重建/草稿不丢/消息行高/个人页路由 59.372 秒。
- `Starry-First-Frame-v020.xcresult`：15.907 秒通过，补充首帧场景存在、实时场景接管后预渲染消失、无加载卡、最终近景和输入框可用。此测试刻意延迟 sceneReady 4 秒以观察过渡，不用于宣称正常启动时间。
- 同一角色连续从消息/发现/我的返回，运行时 presentationId 和 cameraSnapCount 均保持原值，输入草稿保持。日志也实际收到 modelPrewarmed，而非只有预测排名；预热没有改变活动角色。
- simulator/device Unity 导出都通过 immersionRevision=1 与角色/环境目录哈希门禁。只测试 iPhone，本轮没有 iPad 测试或真实设备持续 120 FPS 结论。
