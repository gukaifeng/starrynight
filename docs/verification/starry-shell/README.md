## 明确边界

发布目前只写本机目录，另一个本机体验身份能发现公开角色；没有真实服务器、外部用户市场、上传或跨设备同步。三个常规登录入口仍是同一预填体验身份 A，B 用于隔离验证。角色创建基于四个内置底座及其能力，不是文本生成任意新网格。公开资料不包含聊天和记忆。角色实际模型、离线语音及音乐继续复用，文字仍为本地情景库。
