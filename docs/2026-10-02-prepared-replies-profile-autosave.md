# 预缓存交付、资料自动保存与气泡留白

## 用户要求与处理

预缓存场景仍慢，需要检查实际交付；星夜号从 `xy100000001` 递增；资料自动保存，删除保存按钮；“我的”统一字体字号。后续补充 AI 气泡右侧留空、用户气泡左侧留空，统一安装到手机。

服务端在独立 `../starrynight-server` 完成。接话的三个候选原来顺序等待整段生成，现在以概率顺序启动、受既有四槽队列限制并行，仍每分支一组。命中或接管已准备的回复不再等待无关任务取消，也不毁掉其他仍适用的手势/问候储备；未命中的新输入和实际选择后的未选分支仍正确失效。

生产只读汇总确认存在 hit、miss、inflight 和准备失败，包含输出格式错误与缺语音。客户端原来在 preparing=false 后停止检查，即使缓存缺失；结束的准备 Task 也可能一直保留句柄，妨碍补准备。现在释放完成句柄，以 generation 防止旧 Task 覆盖新 Task；检查账户和会话可见性，并在最多三分钟内以约 31 秒间隔补缺项，匹配服务端 30 秒退避。已完成项目复用，不反复生成。缓存过期、对话方向改变、首次冷准备或服务不可用仍可能等待。

资料停止输入 450ms 后自动保存，离开页面立即提交未保存编辑，不自动关闭编辑页面。单写者串行上传头像与版本化资料，保存中产生的新编辑会继续提交，避免老请求覆盖新内容；保持账号 UUID 校验，失败显示错误而不声称已保存。昵称、简介等有效值仍遵守服务端边界。照片保持苹果官方 PhotosPicker 与部分/全部授权流程，处理和服务端存储沿用已有实现。选择默认头像后重新选相同照片仍需确保服务器头像引用切回上传照片。

“我的”主页面姓名、星夜号、简介、统计、菜单和版本文字统一系统字体 15pt；强调通过字重与颜色区分。图标尺寸独立保持。星夜号迁移保留 UUID、注册序号空档以及旧长号/短号退役别名，不重新按现有用户计数。

每条对话使用真实聊天容器可用宽度的 82% 上限（最多 520pt），AI 靠左、用户靠右。限制在消息命中区域外的整体行扩展之前，保留对侧空白，兼容换行、旁白、语音肩部和翻译按钮；没有把整行空白标为气泡触控区域。
